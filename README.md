# 以 Meep 模擬矽光子微環調變器（2D FDTD）

本專案用開源 FDTD 軟體 [Meep](https://meep.readthedocs.io/) 模擬矽光子**微環調變器**（micro-ring modulator），輸出結構平面圖、穿透率對波長的光譜，並自動計算共振波長、Q 值、消光比等指標。程式已包成可重複呼叫的函式，目標是之後接上**逆向設計**（機器學習或最佳化演算法）。

> **狀態：** 模型剛確認為 PN 反向偏壓版本（偏壓、摻雜 → 遷移率 → 有效質量 → 載子變化 → Δn、Δα），指標只保留調變消光比 ER 與相位調變效率。舊模型與舊指標的掃描結果與分析已全部移除，**目前還沒有用新模型完成的系統性掃描結果**。採用 2D 等效折射率近似，結果用來驗證流程與看趨勢，**不代表真實元件的絕對數值**。

## 1. 背景原理

**研究目標。** 以模擬為主，結合機器學習，對微環調變器做逆向設計：給定想要的光學表現（例如亮暗差大、損耗小），由演算法反推環半徑、間隙等結構參數，並比較不同機器學習演算法在準確度與運算時間上的差異。Meep 在這裡扮演「前向模擬器」：給一組結構參數，算出光譜與指標，作為訓練資料與驗證依據。

**Meep 的角色與限制。** Meep 只求解光（麥克斯威方程），不處理電學。因此本專案把「電壓」簡化成「折射率變化 Δn 與吸收變化 Δα」兩個輸入參數，分別跑「電壓 OFF」與「電壓 ON」兩次模擬後比較光譜。Δn、Δα 與載子濃度的關係可由 Soref 公式換算（目前程式以示意值輸入，尚未內建換算）。調變機制是 **PN 反向偏壓的載子空乏型**：環內有一圈接面，反向偏壓使接面兩側的空乏區變寬，空乏區內載子被掃光、折射率上升、吸收消失。電學部分不模擬，空乏區寬度由使用者輸入（見 5.1）。

微環調變器的運作原理（含共振為何會讓直波導出口出現凹谷）請見下一節 2.1。

## 2. 模擬架構

### 2.1 微環調變器怎麼運作

**元件組成。** 一條直波導（bus waveguide）、一個環形波導（ring），兩者之間隔著一條很窄的縫（gap，約 0.1 到 0.2 µm）。光從直波導左端進入、右端（through port）離開，我們量的就是右端剩下多少光。

```
            ┌──────────────┐
         ┌──┘   環 (ring)  └──┐
         │                    │
         └──┐              ┌──┘
            └──────┬───────┘
                   │ gap（耦合區）
 輸入 ═════════════╧═══════════════► 輸出（through port）
              直波導 (bus)
```

**光怎麼進到環裡（耦合）。** 光在波導內傳播時，有一小部分電場會滲到波導外面，稱為倏逝波（evanescent field）。gap 夠窄時，這部分電場會碰到環，把一部分光傳進去。用兩個係數描述：自耦合係數 `t`（直接通過的振幅比例）與交叉耦合係數 `κ`（進入環的振幅比例）。無損耦合器滿足 `t² + κ² = 1`。gap 越小，`κ` 越大，而且 `κ` 隨 gap 近似指數式變化，所以 gap 對耦合強度非常敏感。

**共振條件。** 光在環內繞一圈會累積相位：

```
φ = 2π · n_eff · L / λ        （L = 2πR 為環的周長，n_eff 為等效折射率）
```

繞一圈回來時，若相位剛好是 2π 的整數倍（`φ = 2πm`），這一圈的光與新進來的光同相，一圈一圈疊加，這就是共振：

```
λ_m = n_eff · L / m           相鄰兩個共振的間距（FSR） ≈ λ² / (n_g · L)
```

本專案 R=3 µm 時，FSR 約 41 到 44 nm（粗估），對應群折射率 n_g 約 3；程式用 `N_G`（預設 2.9）估算 FSR。

**為什麼共振時，直波導出口會出現凹谷（核心）。** 出口的光是兩條路徑的疊加，也就是干涉：

- **路徑 A**：光直接沿直波導通過，不進環。振幅是 `t · E_in`。
- **路徑 B**：光先耦合進環，在環裡繞了一圈（或很多圈），再耦合回直波導。耦合進去與耦合出來各帶一次 90° 的相位，合計 180°，所以路徑 B 相對路徑 A 是反相（符號相反）。

兩條路徑如何疊加，取決於繞圈相位 `φ`：

- **共振時（`φ = 2πm`）**：環內的光每一圈都同相累積，路徑 B 的強度很大，而且與路徑 A 反相，產生**相消干涉**，出口的光變少，穿透率 T 出現凹谷。
- **離開共振時**：每一圈的相位不同，不同圈的光互相抵消，路徑 B 很弱，幾乎沒有干涉，T 約等於 1。

換成能量的說法：共振時大量的光被「存」進環裡，環有損耗（材料吸收、彎曲輻射、側壁散射），這些光在環裡被消耗掉，沒有回到直波導，所以出口變暗。

> **重要：** 如果環完全沒有損耗，進環的光最後會全部回到直波導，只有相位被改變，T 永遠等於 1，不會有凹谷。凹谷是「耦合」與「損耗」的平衡所產生的。

令 `a` 為環繞一圈後振幅剩下的比例（`a = 1` 代表無損），標準的全通（all-pass）環形共振器穿透率為：

```
T(φ) = (a² − 2·a·t·cos φ + t²) / (1 − 2·a·t·cos φ + (a·t)²)

共振時（cos φ = 1）：  T_min = ( (a − t) / (1 − a·t) )²
```

**三種耦合狀態。** 凹谷多深，取決於「光進環的速度」與「光在環裡損失的速度」是否相當：

| 狀態 | 條件 | 共振時 T_min | 對應的 gap |
|---|---|---|---|
| 欠耦合（under-coupled） | 進環速度 < 損耗速度（`t > a`） | 凹谷淺 | gap 偏大 |
| 臨界耦合（critical） | 兩者相等（`t = a`） | 理論上降到 0（完全消光） | 剛好 |
| 過耦合（over-coupled） | 進環速度 > 損耗速度（`t < a`） | 凹谷又變淺 | gap 偏小 |

用 Q 值表示更直觀：令 `Q_c` 對應「光耦合進出環」的速率、`Q_i` 對應「環自身損耗」的速率（Q 越大代表速率越慢），則

```
1/Q_L = 1/Q_i + 1/Q_c                  （Q_L 是實際量到的 Q，FWHM = λ₀ / Q_L）
T_min = ( (1/Q_i − 1/Q_c) / (1/Q_i + 1/Q_c) )²
```

當 `Q_c ≫ Q_i`（進環很慢）就是欠耦合，凹谷很淺；`Q_c = Q_i` 是臨界耦合。

**怎麼拿來做調變器。** 對矽施加電壓，改變載子濃度，透過電漿色散效應（Soref 效應）改變折射率 `Δn`（以及吸收 `Δα`），等效折射率 `n_eff` 改變，繞圈相位 `φ` 隨之改變，共振波長位移：

```
Δλ ≈ λ · Δn_eff / n_g
```

雷射波長固定，放在凹谷的斜坡附近。電壓 ON/OFF 時凹谷左右移動，雷射波長處的穿透率隨之改變，亮暗即對應 1 與 0。亮暗差（OMA）取決於兩件事：位移相對於凹谷寬度（`Δλ / FWHM`），以及凹谷夠不夠深（ER）。吸收的改變 `Δα` 則會改變 `a`，進而改變凹谷的深度與寬度。

**Meep 在這裡做什麼。** Meep 不使用上面的公式，而是直接在空間與時間的格點上推進麥克斯威方程：從直波導左端送入一個寬頻脈衝，等光通過、環內的光漏完之後，對出口記錄到的場做傅立葉轉換，得到各波長的穿透率。上面的公式只用來「解讀」模擬結果、判斷設計落在哪個耦合狀態。

### 2.2 模擬流程

```
              y
              ^        ┌──────────┐
              |      ┌─┘   環     └─┐        環：圓心在 (0,0)，中心線半徑 R
              |      │    (矽)      │        直波導：位於環下方，gap 為間隙
              |      └─┐          ┌─┘
              |        └──────────┘
   光源 ─►  ═════════════════════════════►  through 監測器
              └──────────── 直波導 ───────────> x
```

1. **幾何**：矽（等效折射率 2.8）的直波導與環，背景為 SiO₂（折射率 1.44），四周為 PML 吸收邊界。
2. **光源**：直波導左端放寬頻高斯脈衝（Ez 極化）。
3. **監測**：直波導右端（環的耦合區之外）放 flux 監測器，記錄各頻率的穿透功率。
4. **三次模擬**：
   - 參考：只有直波導，用來扣掉光源頻譜與波導本身的影響。
   - 電壓 OFF / ON：OFF（零偏壓）與 ON（反向偏壓）都是有基線吸收的摻雜矽，差別只在環內接面兩側的空乏區寬度（OFF 窄、ON 寬）。
5. **歸一化**：穿透率 `T(λ) = 有環的功率 / 參考功率`。
6. **指標萃取**：從 `T(λ)` 抓出凹谷位置、半高寬、Q、消光比，並比較 OFF/ON 得到調變指標。
7. **有效性檢查**：檢查凹谷是否可信（見第 8 節），不合格則標記無效或自動重試。
8. **停止條件**：等環內場衰減到 `DECAY` 以下才停止（Q 越高跑越久）。

## 4. 使用方式

```bash
# 單核執行
python micro_ring_modulator_meep.py

# 平行執行（需安裝 MPI 版 Meep）
mpirun -np 4 python micro_ring_modulator_meep.py
```

執行結束後，終端機會印出各項指標，並在目前資料夾產生圖檔與光譜資料。

放大圖的範圍由程式開頭的 `PLOT_ZOOM` 控制（兩個凹谷外側各多留幾倍 FWHM，預設 1.5，數字越小畫面越放大）。長時間模擬跑完後，想調整圖的範圍，不必重跑 Meep：

```bash
python replot_from_npz.py --zoom 1.0            # 更放大
python replot_from_npz.py --xlim 1537 1542      # 手動指定 x 軸範圍 (nm)
```

**第一次使用建議先用低成本設定確認流程**：在 `PARAMS` 中把 `RESOLUTION` 設為 20 到 25、`NFREQ` 設為 200 到 600，確認結果合理後再提高解析度與降低 `DECAY`。

## 5. 參數說明

所有參數集中在程式開頭的 `PARAMS`（長度單位 µm）。參數分兩類：**設計參數**是真實元件的結構或物理量，是逆向設計要調整的旋鈕；**數值參數**只影響模擬算得準不準、跑多久，不是設計的一部分。

| 參數 | 預設值 | 類型 | 說明 |
|---|---|---|---|
| `R` | 3.0 | 設計 | 環中心線半徑 |
| `W` | 0.5 | 設計 | 波導寬度（環與直波導相同） |
| `GAP` | 0.20 | 設計 | 直波導邊緣與環邊緣的間隙，決定耦合強度 |
| `PN_FROM_PHYSICS` | True | 設計 | True：由下面 5 個物理參數算出 `DN_DEPL`、`W_DEPL_OFF`、`W_DEPL_ON`（見 5.2）；False：直接用手填的那三個值 |
| `V_REV` | 2.0 | 設計 | 反向偏壓大小 (V)，填正數 |
| `NA`、`ND` | 5e17 | 設計 | p 側、n 側摻雜濃度 (cm⁻³) |
| `TAU_MP`、`TAU_MN` | 3.13e-14、3.77e-14 | 材料 | 電洞、電子的動量散射時間 (s)，視為定值 |
| `LAMBDA_PHYS_UM`、`N_SI_BULK` | 1.55、3.476 | 材料 | 算 Δn 公式裡的波長與體材矽折射率 |
| `COMPUTE_EFFECTIVE` | False | 設計 | True：多跑一次 OFF 模擬，用共振場 \|E\|² 做加權平均，算有效折射率變化 Δn_eff 與有效損耗變化 Δα_eff（見 5.3），結果放在 `evaluate` 回傳 dict 的額外鍵，不進 CSV |
| `EFF_MARGIN` | 0.3 | 數值 | 場加權積分範圍：環的內外緣各外擴多少 (µm)，把消逝場算進分母 |
| `EFF_EXCLUDE_BUS` | 1.0 | 數值 | 場加權積分時，剔除離直波導上緣這個距離 (µm) 以內的格點，避免直波導的行進波與消逝場混進 \|E\|²；環上的分布沿角度近似均勻，剔除一個扇形不影響比值 |
| `ALPHA_DOPE` | 7.0 | 設計 | （`PN_FROM_PHYSICS=False` 才用）摻雜矽的基線吸收（cm⁻¹）；True 時由第五步算出 |
| `ALPHA_DEPL` | 0.0 | 設計 | （同上）空乏環帶的吸收（cm⁻¹，不可為負）；True 時 = 基線 + Δα，下限 0 |
| `DN_DEPL` | 0.0017 | 設計 | （`PN_FROM_PHYSICS=False` 才用）完全空乏的區域，折射率比摻雜矽高多少（正值，示意值） |
| `W_DEPL_OFF` | 0.06 | 設計 | （同上）OFF（零偏壓）的空乏區寬度 (µm) |
| `W_DEPL_ON` | 0.12 | 設計 | （同上）ON（反向偏壓）的空乏區寬度 (µm)，比 OFF 寬 |
| `X_JUNC` | 0.0 | 設計 | 接面位置，相對環中心線的徑向偏移 (µm)，正值往外；內側為 p、外側為 n |
| `N_SI` | 2.8 | 材料 | 矽的等效折射率（2D 近似） |
| `N_CLAD` | 1.44 | 材料 | 包覆層 SiO₂ 的折射率 |
| `RESOLUTION` | 40 | 數值 | 每 µm 的像素數 |
| `NFREQ` | 4000 | 數值 | 頻率取樣點數，決定光譜的細緻度；PN 位移只有約 0.1 nm，窗口 20 nm 時 4000 點的間隔是 0.005 nm |
| `DECAY` | 1e-6 | 數值 | 場衰減到多小才停止，越小越準但越慢 |
| `USE_HARMINV` | True | 在 OFF 的環模擬中加 Harminv，直接從時域衰減量 Q（尚未在真實 Meep 上驗證；出錯時改成 False） |

| `WVL_MIN`, `WVL_MAX` | 1.525, 1.545 | 數值 | 掃描波長範圍（要小於 FSR，且涵蓋 OFF 與 ON 的凹谷；預設值是解析度 40、R=3 時共振約 1535 nm 的位置，換解析度或 R 要重設，見 10.1） |

### 5.1 調變機制：PN 反向偏壓

環裡放一圈 PN 接面（p 在內側、n 在外側，接面在 `R + X_JUNC`）。**OFF（零偏壓）** 空乏區窄；**ON（反向偏壓 `V_REV`）** 空乏區變寬，多出來的那一圈載子被掃光。載子變少使折射率上升（`Δn` 為正，共振往**長**波長移）、自由載子吸收下降（`Δα` 為負）。`Δn`、`Δα` 與空乏區寬度由偏壓、摻雜與散射時間算出，見 5.2；光場與空乏區的重疊見 5.3。

**考慮的點：**

1. **吸收不能是負的。** Meep 的吸收（電導率）只能為正，「損耗變少」要靠基線表示：環內摻雜矽有基線吸收 `ALPHA_DOPE`，空乏環帶的吸收 `ALPHA_DEPL` = 基線 + `Δα`（最低為 0）。`PN_FROM_PHYSICS=True` 時兩者由摻雜算出。
2. **作用區域要放在幾何上。** 在環裡加一圈以接面為中心、寬 `W_DEPL_ON` 的環帶（`depletion_edges`、`build_geometry`），環帶不會超出環的內外緣。OFF 不放環帶（`Δn` 已是相對 0 V 的變化）。這是 2D 簡化：環帶左右對稱，`Na = Nd` 時與真實分布吻合；`Na ≠ Nd` 時空乏區會偏向低濃度側，需要另外處理（見專案文件 `plan-na-nd-asymmetric-doping.md`）。
3. **空乏區很薄，要注意解析度。** 預設的空乏區約 0.12 µm，在解析度 25（像素 40 nm）只有約 3 個像素；Meep 靠次像素平滑處理介面，但 ON 與 OFF 的差別只是這一圈的折射率差（約 2×10⁻⁴），數值誤差可能與它同量級。解析度收斂測試要用新模型重做。
4. **位移很小，量測要變細（已處理）。** 位移約 0.04 nm，和頻率取樣間隔同量級。程式做了兩件事：預設 `NFREQ` 提高到 4000（窗口 20 nm 時間隔 0.005 nm，只增加記憶體，不增加模擬時間）；`shift_nm` 是「OFF 與 ON 兩個洛倫茲擬合中心的差」，擬合失敗才退回離散最低點的差，位移可以細過取樣間隔。
5. **位移小於線寬，調變指標會很小。** 位移通常遠小於凹谷的半高寬，所以 ER 偏小；提高 Q（凹谷變窄）、增加空乏寬度的變化、或改看每伏特的效率，都是可能的方向，但 Q 提高會增加光子壽命、降低頻寬，這個取捨目前沒有模擬。
6. **掃描資料的版本。** `sweep_resolution_gap.py` 的預設輸出是 `sweep_results_pn.csv`，開頭會印出目前的 PN 參數；任何用別的物理參數跑出來的 CSV 請換新的 `--out`，不要混在同一個檔。
7. **沒有模擬的部分。** 電學（偏壓與空乏寬度的實際關係、電容、RC 頻寬）、真實的摻雜分佈（垂直或水平接面、摻雜濃度的空間分佈）、摻雜造成的折射率偏移（已併入 `N_SI`）、極化（Ez 對應準 TM，真實 PN 調變器多為準 TE）都沒有。

**程式的對應（`micro_ring_modulator_meep.py`）：**

- `PARAMS`：PN 參數 `PN_FROM_PHYSICS`、`V_REV`、`NA`、`ND`、`TAU_MP`、`TAU_MN`、`ALPHA_DOPE`、`ALPHA_DEPL`、`DN_DEPL`、`W_DEPL_OFF`、`W_DEPL_ON`、`X_JUNC`（說明見參數表）。
- `depletion_medium(p)`、`depletion_edges(p, depl_width)`：前者回傳空乏區材料（折射率 `N_SI + DN_DEPL`、吸收 `ALPHA_DEPL`）；後者算出空乏環帶的內外半徑，並夾在環的內外緣之間。
- `build_geometry(p, with_ring, ring_medium, depl_width)`：`depl_width` 大於 0 時，在環裡依序放「空乏材料的外圓」、「環材料的內圓」，疊出一圈環帶，最後仍用包覆層的內圓挖空。Meep 後放的物件蓋過先放的，所以順序不能換。
- `_simulate_once`：OFF 與 ON 用同一種摻雜矽（`si_medium(N_SI, 0, ALPHA_DOPE)`），只有空乏寬度不同（`W_DEPL_OFF` 與 `W_DEPL_ON`）。
- `evaluate`：先由 `resolve_pn_params` 算出物理參數，再對 ON 的凹谷做洛倫茲擬合，用兩個擬合中心的差當 `shift_nm`。
- `plot_structure`：畫出接面（虛線）、OFF 與 ON 的空乏區邊界，並標示 p、n 兩側與 PN 參數（空乏區在介電常數圖上看不出來）。曲線圖例是「OFF (0 V)」與「ON (reverse bias)」。

**驗證狀況。** 用預設參數在 Meep 跑過一組：共振位移為 +0.040 nm（正值、紅移），與手算的一階估計一致，ER 約 0.05 dB。其他部分（取場、場加權公式）的驗證狀況分別寫在 5.2、5.3。

### 5.2 由偏壓與摻雜算出 `DN_DEPL` 與空乏區寬度（`PN_FROM_PHYSICS=True`）

原本 `DN_DEPL`、空乏區寬度是手動猜的。現在固定 **反向偏壓 `V_REV`、摻雜 `NA`、`ND`、散射時間 `τ`**，由程式依四個步驟算出來（函式 `pn_carrier_physics`，程式開頭印出每一步的數字，可用 `print_pn_physics` 單獨檢查）：

| 步驟 | 算什麼 | 公式 |
|---|---|---|
| 一 | 遷移率 μp、μn (cm²/V·s) | μp = 420/(1+[(Na+Nd)/1.6×10¹⁷]^0.7) + 50；μn = 1318/(1+[(Na+Nd)/1×10¹⁷]^0.85) + 92 |
| 二 | 有效質量 m_p、m_n | μ = qτ/m，所以 m = qτ/μ（τ 是定值，m 會隨摻雜改變） |
| 三 | 偏壓下的空乏區寬度與 ΔNh、ΔNe | Vbi = (kT/q)·ln(NaNd/ni²)；W = √(2ε(Vbi+V)/q·(1/Na+1/Nd))；Na、Nd 是原本的摻雜（定值），偏壓只把空乏區往外推；ΔN 以 0 V 為基準：新增那一層的載子被掃光，平均到偏壓下的空乏深度，ΔNh = −Na·(xp(V)−xp(0))/xp(V)，ΔNe 同理（V = 0 時為 0） |
| 四 | 折射率變化 Δn | Δn = −(e²λ²/(8π²c²ε0 n))·[ΔNe/m*_ce + ΔNh/m*_ch] |
| 五 | 損耗變化 Δα（自由載子吸收） | Δα = (e³λ²/(4π²c³ε0 n))·[ΔNe/(m*_ce²·μe) + ΔNh/(m*_ch²·μh)]；載子被掃光 (ΔN<0) 所以 Δα 為負（損耗變小） |

**預設值的結果**（V = 2 V、Na = Nd = 5×10¹⁷ cm⁻³）：μp = 141.2、μn = 255.1 cm²/V·s；m_p = 0.39 m0、m_n = 0.26 m0；Vbi = 0.917 V；空乏區寬度 0.069 µm（0 V）→ 0.123 µm（2 V）；平均 ΔNh = ΔNe = −2.2×10¹⁷ cm⁻³（約為 Na 的 44%）；Δn_電子 = +2.62×10⁻⁴、Δn_電洞 = +1.75×10⁻⁴，寬度加權平均 `DN_DEPL` = +2.18×10⁻⁴。模擬時 OFF（0 V）不放環帶，ON 放寬 0.123 µm、折射率 +2.18×10⁻⁴ 的環帶（相對 0 V 的變化）。這些數字已用手算核對過。

**損耗（第五步）的預設結果：** 摻雜矽的基線吸收 `ALPHA_DOPE` = 0.95 cm⁻¹（4.1 dB/cm）：把全部載子（Nd 個電子、Na 個電洞）代進同一條式子，p、n 各占環寬一半取平均；偏壓造成的平均 Δα = −0.42 cm⁻¹，所以空乏環帶的吸收 = 0.95 − 0.42 = 0.53 cm⁻¹。電子那一項用獨立手算核對過（1.05 cm⁻¹）。Meep 的吸收不能是負的，所以用「環的基線吸收」與「空乏環帶的吸收」兩個非負值表示（`ALPHA_DOPE`、`ALPHA_DEPL`）。

**損耗的注意事項：**

- **數值比之前小很多：** 之前的 `ALPHA_DOPE = 7` cm⁻¹ 是用 Soref 的經驗係數估的；用 Drude 公式加上這裡的 τ 與遷移率算出來只有 0.95 cm⁻¹，差約 7 倍（Drude 模型本來就比實驗擬合的 Soref 係數低）。環的損耗變小後，耦合狀態會改變（容易變成過耦合、凹谷變淺），舊的掃描結果不能直接比較。
- **兩套係數可以對照：** 若你更相信 Soref 的結果，把 `PN_FROM_PHYSICS=False` 並手填 `ALPHA_DOPE`、`ALPHA_DEPL` 即可；也可以只調 `TAU_MP`、`TAU_MN`，但 τ 會同時改變 Δn 與 Δα。
- 環只有 p、n 兩半的平均，沒有考慮空乏區外的金屬接觸、波導粗糙度等其他損耗。

**要注意的地方：**

1. **ΔN 的定義：** Na、Nd 是固定的摻雜，不是偏壓產生的。ΔN 是偏壓造成的變化，以 0 V 為基準（V = 0 時 ΔN = 0、Δn = 0）；用完全空乏近似，實際空乏邊緣有緩變區。因為 Δn 是相對 0 V，OFF 的絕對共振波長不含 0 V 空乏區的貢獻，但這不影響位移。
2. **τ 是我填的預設值：** 用「Na+Nd = 10¹⁸ 時 m_p = 0.39 m0、m_n = 0.26 m0」反推。你若有自己的 τ（或老師給的），請改 `TAU_MP`、`TAU_MN`。
3. **位移比之前小：** 先前的 `DN_DEPL = 0.0017` 是用 Soref 公式估的；新算法「Δn × 環帶寬度」約 2.7×10⁻⁵ µm，先前約 0.0017×0.06 = 1.0×10⁻⁴ µm，約小 3.8 倍，所以預期共振位移縮小到約 0.04 nm（未經 Meep 驗證）。位移這麼小，要先確認解析度造成的雜訊（見 10.1）不會蓋過它。
4. **沒有處理的部分：** 這是 2D 近似，Δn 是體材矽的值，沒有換算成導波模態的等效折射率變化（重疊因子）；p、n 兩側用寬度加權平均成單一折射率環帶，不是左右兩個不同的區域；偏壓不改變 `ALPHA_DOPE`。
5. `PN_FROM_PHYSICS=True` 時，手填的 `DN_DEPL`、`W_DEPL_OFF`、`W_DEPL_ON` 會被蓋掉（`W_DEPL_OFF` 固定為 0）；掃描時請注意不要中途改 `V_REV`、`NA`、`ND`、`τ`（同第 9.1 節的規則，要改請換新的 `--out`）。

### 5.3 有效折射率與有效損耗（場加權公式）

公式出處見參考文獻 [5]。

```
Δn_eff = ∬_S Δn_c(x,y)·|E(x,y)|² dxdy / ∬_S |E(x,y)|² dxdy
Δα_eff = ∬_S Δα_c(x,y)·|E(x,y)|² dxdy / ∬_S |E(x,y)|² dxdy
```

意思：載子造成的折射率（損耗）變化，只有光場所在的位置才有貢獻，所以用光強 `|E|²` 當權重取平均。程式在 `effective_from_field`（純 numpy 的計算）與 `effective_index_loss`（跑 Meep 取場），把 `COMPUTE_EFFECTIVE` 設成 True 即可使用。

**2D 模型怎麼對應這個公式。** 公式裡的 S 是垂直於傳播方向的截面。我們的 Meep 是 2D，模擬平面是環的俯視圖，光沿環的角度 φ 傳播，所以垂直於傳播方向的截面只剩徑向 r 這一條線，垂直方向（z）已被等效折射率吸收。實作上對環形區域的每個格點取 `|Ez|²`，用 Meep 給的面積權重 `w` 積分（`∬ dA = r dr dφ`），結果等於以 r 為權重的徑向加權平均。2D 的電場只有 Ez（光源是 Ez，TM 偏振），所以 `|E|² = |Ez|²`。

**`Δn_c`、`Δα_c` 的分布。** 取「新增空乏層」（相對 0 V）：接面在 `R + X_JUNC`，p 在內側、n 在外側，偏壓使空乏深度從 0 V 的 `(xp_off, xn_off)` 擴到 `(xp_on, xn_on)`；新增層內載子被掃光（`ΔN = −Na` 或 `−Nd`），其餘位置為 0，且只有矽內才有載子。`Na ≠ Nd` 時兩側新增層的厚度與 `Δn` 都不同，公式自然會處理。

**Meep 怎麼在特定座標取電場。**

| 方法 | 取到什麼 | 用在哪 |
|---|---|---|
| `sim.get_field_point(mp.Ez, mp.Vector3(x, y))` | 某一個座標、某一個時刻的場（實數） | 看單點的時域訊號 |
| `sim.get_array(center=, size=, component=)` | 一塊區域每個格點的瞬間場，或介電常數（`mp.Dielectric`） | 畫結構圖（本程式用來取 ε） |
| `sim.add_dft_fields(...)` 加 `sim.get_dft_array(dft, mp.Ez, 0)` | 某個頻率的複數場（頻域）：執行期間每個時間步把 `E(t)·e^{iωt}·dt` 累加起來 | **本程式用這個**，因為要的是共振頻率的場分布 |

細節：(1) Meep 的場存在 Yee 格上，Ez、Hx、Hy 各自錯開半格；取值時會線性內插到格點中心，所以座標與陣列對齊。(2) `sim.get_array_metadata(dft=...)` 回傳該區域的格點座標 `x`、`y` 與積分權重 `w`（`∑ f·w ≈ ∬ f dA`），公式的積分直接用它。(3) 用 MPI 平行時，`get_array`、`get_dft_array` 是集體操作，每個 rank 都要呼叫，且每個 rank 都會拿到完整陣列。(4) DFT 只記一個頻率（共振波長），記憶體與時間成本很小；但共振波長要先量出來，所以 `evaluate` 要多跑一次 OFF 模擬。

**直波導的污染。** 直波導裡是強的行進波，消逝場會漏進環與波導之間的縫隙，混進 `|E|²`（分母偏大）。所以積分剔除離直波導上緣 `EFF_EXCLUDE_BUS`（預設 1 µm）以內的所有格點。用合成場測試：直波導場為環場 3 倍時，不剔除會讓 `Δn_eff` 偏小約 5%，剔除後完全消除。這個假設（環上共振場沿角度近似均勻，光源只激發單一方向的行進波）沒有在真實場上驗證。

**位移的對照。** 程式同時給兩個由 `Δn_eff` 換算的位移，可以和 Meep 直接量到的 `shift_nm` 比較：(a) `Δλ ≈ λ·Δn_eff / n_g`（用你的公式與 `N_G`）；(b) 嚴格的一階微擾 `Δλ/λ = ∬ n·Δn·|E|² / ∬ n²·|E|²`（用實際的折射率分布，不需要 `n_g`）。回傳鍵：`dn_eff`、`dalpha_eff_cm`、`gamma_p`、`gamma_n`（光場落在 p、n 側新增層的比例）、`shift_pert_nm`、`shift_pert_eps_nm`。

**驗證狀況與限制：**

1. **只驗證了 numpy 的部分。** 用合成的場（徑向高斯乘方位駐波）算出的結果，與獨立的一維徑向積分一致（`Δn_eff` 差約 1.7%，`Δα_eff` 差約 1.8%）。**取場那一段（`add_dft_fields`、`get_array_metadata`、`get_dft_array`）沒有在真實 Meep 上跑過**，這個容器沒有安裝 Meep，請你先在小解析度跑一次確認。
2. **新增層很薄。** 預設的新增層厚度約 0.027 µm，在解析度 40 只有約 1 個像素，積分的離散誤差會變大；解析度低時請當趨勢看。
3. **仍是 2D 近似。** `Δn_c` 是體材矽的值，沒有乘 3D 的垂直重疊（光場落在矽裡的比例），所以 `Δn_eff` 是 2D 等效折射率的變化，絕對值偏大或偏小都有可能，比較不同設計之間的相對值較可信。
4. **和 Meep 的 ON 幾何略有差別。** ON 模擬用的是「以接面為中心、寬 `W_ON`、平均 Δn」的單一環帶，公式用的是真實的新增層分布。用合成場粗估，兩者的 `Δn_eff` 差約 2% 到 16%（場越窄差越多）。要完全一致，需實作 `Na ≠ Nd` 計畫裡的方案 A（內外兩段環帶），見專案文件 `plan-na-nd-asymmetric-doping.md`。

## 7. 指標定義

目前只保留兩個指標：**調變消光比 ER** 與 **相位調變效率**。原本的 Q、FWHM、OMA、IL、單一凹谷深度、Harminv 等指標已從輸出移除（程式內部仍用凹谷的位置與寬度做有效性檢查，但不再輸出）。

| 指標 | 欄位 | 定義 |
|---|---|---|
| 調變消光比 ER | `ER_dB` | `10·log10(亮 / 暗)`：雷射放在「\|T_on − T_off\| 最大」的波長 `λ_L`，比較 ON、OFF 兩個狀態的穿透率，亮的那個除以暗的那個。這是調變器真正的 ER（不是單一凹谷的深度），目標是 3 dB 以上。 |
| 相位調變效率 η | `phase_eff_rad_per_V` | `Δφ / V_REV`（rad/V），環一圈的相位變化除以反向偏壓，越大越好。 |
| 相位調變效率 VπL | `VpiL_Vcm` | `V_REV · L · π / \|Δφ\|`（V·cm），讓相位改變 π 所需的「電壓 × 長度」，越小越好。`L = 2πR` 是環周長。 |
| 中間量：共振位移 | `shift_nm` | OFF 與 ON 兩個凹谷的洛倫茲擬合中心之差（nm）。相位效率由它算出，也是判斷「位移有沒有被雜訊蓋過」的依據，所以保留。 |
| 中間量：OFF 共振波長 | `lam0_off_nm` | 掃描時用來追蹤下一組的窗口中心，所以保留。 |

### 7.1 相位調變效率怎麼算

調變效率與 VπL 的一般定義與文獻比較見參考文獻 [6]。

環共振時，光繞一圈的相位是 2π 的整數倍。共振波長移動 `Δλ`，等於繞一圈的相位多了 `Δφ`：

```
FSR = λ² / (n_g · 2πR)        自由頻譜範圍（相鄰共振的間距）
Δφ  = 2π · Δλ / FSR           環一圈的相位變化 (rad)
η   = Δφ / V_REV              (rad/V)
VπL = V_REV · (2πR) · π / |Δφ|   (V·cm)
```

驗算：R = 3 µm、`n_g` = 2.9、λ = 1.54 µm 時 FSR 約 41.6 nm；位移 0.04 nm 對應 Δφ = 0.0058 rad，V = 2 V 時 η = 2.9×10⁻³ rad/V、VπL = 2.04 V·cm（已用合成光譜驗證程式與手算一致）。

**要注意的地方：**

1. **`n_g`（`PARAMS["N_G"]`，預設 2.9）是估計值。** Meep 窗口只含一個共振時量不到 FSR，所以用估計的群折射率；`n_g` 差 10%，相位效率也差 10%。掃描腳本的 `--ng-est` 會同時決定窗口寬度與相位效率用的 `n_g`。
2. **`VπL` 的 L 取環周長。** 光在環裡繞很多圈，這裡算的是「單圈」的 `VπL`；文獻若用有效長度（含 Q 帶來的繞圈數），數字會不同，比較時要確認定義。
3. **位移很小時結果會被雜訊影響。** 目前的物理參數預期位移約 0.04 nm，與解析度造成的誤差可能同量級；`shift_nm` 為 0 或量不到時 `VpiL_Vcm` 留空，並在有效性檢查中被當成不可用（`figure_of_merit` 回傳懲罰分數）。
4. **`V_REV` 只在算效率時當分母。** `PN_FROM_PHYSICS=False` 時，偏壓與空乏區是手填的，`V_REV` 就只是「你宣稱的電壓」，請自行確認與手填的空乏區寬度一致。

### 7.2 CSV 欄位逐欄說明

`sweep_resolution_gap.py` 輸出的 CSV 共 14 欄。數值算不出來時該格留空白。「OFF」指 0 V、「ON」指反向偏壓 `V_REV`（PN 模式的空乏區變寬，見 5.1、5.2）。

| 欄位 | 單位 | 意義 |
|---|---|---|
| `resolution` | 像素/µm | 解析度（輸入）：Meep 把每 1 µm 切成幾格，是數值精度，不是設計參數。 |
| `gap` | µm | 直波導邊緣到環外緣的最短距離（輸入）。越小耦合越強。 |
| `R` | µm | 環中心線的半徑（輸入）。 |
| `valid` | TRUE/FALSE | 有效性檢查是否通過；FALSE 的列其他數值只供除錯，不要拿去訓練。 |
| `reason` | 文字 | 無效的原因；有效時為 `ok`。 |
| `window_min_nm`、`window_max_nm` | nm | 最後實際使用的掃描窗口；重試後可能與起始值不同。 |
| `lam0_off_nm` | nm | OFF 凹谷最低點的波長（窗口追蹤用）。注意它會隨解析度漂移（見 10.1）。 |
| `shift_nm` | nm | 共振位移（ON − OFF），正值為紅移；相位效率由它換算。 |
| `ER_dB` | dB | 調變消光比，定義見第 7 節。 |
| `phase_eff_rad_per_V` | rad/V | 相位調變效率 η。 |
| `VpiL_Vcm` | V·cm | 相位調變效率 VπL。 |
| `retries` | 次 | 為了讓結果通過檢查而自動重試的次數（0 到 2）。 |
| `elapsed_s` | 秒 | 這一組 `evaluate` 的牆鐘時間，只能在同一台機器、同樣的設定下比較。 |

**舊版 CSV 與試算表：** 舊版的 23 欄 CSV 欄位和現在不同，續跑腳本會拒絕載入，請改名備份或換新的 `--out`。`mrm_cross_compare.xlsx` 與 `mrm_sweep_analysis*.xlsx` 讀的是舊的 23 欄（Q、OMA、IL 等），**尚未更新**，新的 CSV 不能直接貼進去。

## 8. 資料有效性檢查

逆向設計會用大量不同參數呼叫 `evaluate`。參數一改，共振位置就會移動（例如 `R` 變 1.7%，共振約移 26 nm），可能跑出掃描窗口、窗口內出現兩個共振，或模擬沒跑到收斂。這些情況下 `analyze_dip` 仍會算出數字，但數字是錯的。因此 `evaluate` 會對 OFF 與 ON 兩條光譜做檢查，並在回傳的字典中帶有 `valid` 與 `reason`：

| 錯誤代碼 | 意義 | 自動處理 |
|---|---|---|
| `not_converged` | T 明顯大於 1，環內的光還沒漏完就停了 | 把 `DECAY` 縮小 100 倍後重跑 |
| `no_dip` | 凹谷深度低於 0.1 dB（共振可能完全在窗口外，或耦合太弱而太淺） | 無法自動修正 |
| `edge_low` / `edge_high` | 凹谷在窗口邊緣，可能被切掉 | 朝凹谷那一側平移窗口後重跑 |
| `incomplete` | 凹谷量不到半高寬 | 同上，平移窗口 |
| `multi` | 窗口內有多個共振。判斷方式：先做 5 點移動平均、以中位數為基線，再用遲滯（低於「基線 − 0.3 倍深度」算進入凹谷，回升到「基線 − 0.1 倍深度」以上才算離開）數凹谷個數，避免雜訊在門檻附近來回穿越而把一個凹谷誤數成多個 | 無法自動修正，請縮小 `WVL_MIN`、`WVL_MAX` 或改 `R` |

模擬本身失敗（當機、記憶體不足）也會被攔下，回傳 `valid=False`，不會讓批次中斷。

**限制：** 窗口追蹤只在共振「剛好跑出邊緣、仍看得到凹谷的一側」時有效（以預設參數約為 `R` 變動 1% 內）。若共振完全離開窗口，光譜是平的，程式無法知道該往哪個方向移，會回報 `no_dip`。此時請用 `predict_center` 預測共振位置，並透過 `center_um` 引數放置窗口。

**`predict_center` 也有限制：** 它假設「同一個階數 m」，即 λ 與 R 成正比，所以只適用 R 小幅變動。R 從 3 變成 5 µm 時，同一階的共振會從約 1540 nm 跑到約 2570 nm，完全不是我們要的波段。R 大幅變動時請改用 `ISOLATE_DIP`：窗口取約 1.1 個 FSR 寬（窗口內至少有一個完整的共振，不必知道它在哪），再讓 `evaluate` 只分析最深的那一個。`sweep_resolution_gap.py --Rs` 就是這樣做的（見第 9 節）。這套檢查邏輯用合成光譜測試過。

**門檻的現況：** `no_dip` 的門檻 0.1 dB 是經驗值。凹谷深度低於門檻的設計會被標為 `valid=False`，但那不一定是模擬失敗，可能只是真實但很淺的凹谷；`valid` 只代表「過了深度門檻」，不代表品質。建議之後把門檻降到約 0.05 dB（約為雜訊的數倍），並注意 `check_dip` 先判 `no_dip`、後判 `edge_low`，被窗口切掉的淺凹谷會被誤判成 `no_dip`（尚未修改）。

**`valid=False` 時，其餘數值僅供除錯，不要拿去訓練。**

## 9. 解析度、gap 與 R 掃描

`sweep_resolution_gap.py` 批次掃描「環半徑 R × 間隙 gap × 解析度」，每組結果寫入 CSV。**掃出來的數值怎麼讀，見 9.3。** 注意：`mrm_cross_compare.xlsx` 還是舊欄位，尚未更新（見 7.2）。

```bash
# 解析度收斂測試（gap、R 固定）
python sweep_resolution_gap.py --resolutions 25 40 50 --gaps 0.20

# gap 掃描（解析度、R 固定）
python sweep_resolution_gap.py --resolutions 40 --gaps 0.10 0.12 0.15 0.20

# R 掃描：R 大時每組很慢，建議先從 4、5 開始
python sweep_resolution_gap.py --Rs 4 5 --gaps 0.12 --resolutions 25

# 完整交叉掃描：R × gap × 解析度 全部組合（下例 4×4×3 = 48 組），用 4 個 MPI 程序
mpirun -np 4 python sweep_resolution_gap.py --Rs 3 3.5 4 5 --gaps 0.08 0.10 0.12 0.15 --resolutions 25 40 50
```

**掃 R 的做法。** R 一變，共振位置會跑得很遠，無法預測（見第 8 節）。所以這個模式不放窗口在預測位置，而是：

- 窗口取 1.1 個 FSR 寬（`FSR = λ² / (n_g · 2πR)`，`n_g` 預設 2.9，可用 `--ng-est` 調整），窗口中心設在 `--target-nm`（預設 1540 nm）；
- 頻率取樣間隔約 0.02 nm（`--spacing-nm`），頻率點多只增加記憶體，不增加模擬時間；
- 分析時只取最深的那個凹谷兩側各 0.45 倍 FSR 的資料（`ISOLATE_DIP`），其餘共振丟掉。

模擬時間主要由環內的光漏完要多久決定，與窗口寬度幾乎無關，所以放寬窗口不會變慢。但 R 變大時計算區域變大（面積約隨 R² 增加），Q 通常也變高，每組都會比 R=3 慢。

**其他特性。**

- 每跑完一組就寫入 CSV；中斷後重新執行同一個指令，已有結果的組合會自動跳過。
- 每組的完整光譜另存到 `sweep_spectra/`，之後可以離線重新分析。
- 不掃 R 時，每組的掃描窗口以上一組有效結果的共振波長為中心（`--center-nm` 指定第一組的位置）。
- 無效結果也會寫入並附原因。
- 預設輸出 `sweep_results_pn.csv`。舊格式（欄位不同、或沒有 R 欄）的 CSV 程式會拒絕寫入並提示改名備份。
- 目前 CSV **沒有記錄** `DECAY` 與 `NFREQ`（沿用 `PARAMS` 的值，掃 R 時 `NFREQ` 由窗口寬度決定），之後建議加入，才能完整重現。

**CSV 欄位（共 23 欄，順序與試算表 A~W 欄一致；逐欄的定義、單位與注意事項見 7.2）：** `resolution`、`gap`、`R`、`valid`、`reason`、`window_min_nm`、`window_max_nm`、`lam0_off_nm`、`lam0_on_nm`、`shift_nm`、`fwhm_nm`、`Q`、`Q_fit`、`Q_fit_err`、`Q_harminv`、`ER_dB`、`ER_fit_dB`、`OMA`、`ER_mod_dB`、`IL_dB`、`lam_L_nm`、`retries`、`elapsed_s`。

**舊的 `mrm_sweep_analysis.xlsx`。** 它的收斂判定要求同一組 (R, gap) 的列相鄰、且解析度遞增，掃描組合一多、分批貼上就會對不上，所以改用 `mrm_cross_compare.xlsx`（依 R、gap、解析度查值，與列的順序無關）。舊檔仍可看單組結果，但不建議再用於多組交叉比對。

### 9.1 暫停與繼續

腳本每跑完一組就寫入 CSV，所以可以隨時停、之後接著跑：

- **暫停：** 前景執行按 `Ctrl+C`；背景執行（`nohup`）用 `pkill -f sweep_resolution_gap.py`。已寫入 CSV 的組合都保留。
- **繼續：** 在同一個資料夾，用同一份 `.py`、同一個 `--out`，原封不動再打一次同一行指令。已有結果的組合會印 `[skip]` 並跳過，只跑剩下的。
- **停下當下正在跑的那一組不會被存下來**，下次從那一組開頭重跑。單組在高解析度可能要十幾分鐘（見第 12 節），盡量等一組剛印出 `[done]` 再停。
- **中途不要改物理設定**（`N_SI`、`V_REV`、`NA`、`ND`、`TAU_MP`、`TAU_MN`、`DECAY` 等）。舊結果會和新結果混在同一個 CSV，卻沒有警告。要改設定請換新的 `--out` 檔名。
- 想放著跑一整晚，建議用 `nohup mpirun -np 4 python sweep_resolution_gap.py ... > sweep.log 2>&1 &`，視窗關掉程序才不會跟著被關。

### 9.2 試算表 `mrm_cross_compare.xlsx`：目前不能用

`mrm_cross_compare.xlsx`（以及 `mrm_sweep_analysis*.xlsx`）讀的是舊的 23 欄（Q、OMA、IL 等），而現在的 CSV 只有 14 欄（見 7.2），**不能直接貼進去**。等新模型的掃描資料累積起來，再依新欄位（`shift_nm`、`ER_dB`、`phase_eff_rad_per_V`、`VpiL_Vcm`）重做交叉比對表。重做時建議保留的設計：依 (R, gap, 解析度) 查值而不是依列的順序，並對同一組合的重複列取平均。

### 9.3 讀掃描數值的規則

1. **只比較同一個解析度的數字。** 解析度不同，共振波長會差好幾 nm（格點造成的系統差），位移與 ER 也會變。跨 R 或跨 gap 比較時，請固定在同一個解析度。
2. **先確認位移穩定。** 位移很小（預設約 0.04 nm），要先看它在不同解析度下是否一致，才能拿 `phase_eff_rad_per_V`、`VpiL_Vcm` 當設計依據；位移不穩時，這兩個數字也不穩。
3. **`valid` 只代表「凹谷深度有沒有超過 0.1 dB 門檻、窗口與收斂檢查有沒有過」，不是品質分數。** 深度在門檻附近時，同一組設計可能隨解析度在 True 與 False 之間跳。
4. **凹谷很淺（< 0.2 dB，約 5%）時，`ER_dB` 不可靠。** 此時 ER 與雜訊同量級，只能看趨勢。
5. **`ER_dB` 與相位效率要一起看。** `ER_dB` 同時受位移與吸收變化影響；`phase_eff_rad_per_V` 只反映位移（相位）。兩者可能互相抵觸（見 7.1）。
6. **用來訓練機器學習前：** 只取 `valid=True` 的列；整批資料固定同一個解析度；輸入特徵取 R、gap、`V_REV`、`NA`、`ND` 等設計參數，目標取 `ER_dB`、`VpiL_Vcm`；`lam0_off_nm` 的絕對值不要當目標，因為它受解析度影響。

## 10. 限制與注意事項

- **2D 等效折射率近似**：以固定的 `N_SI` 取代真實矽波導的三維模態，絕對的共振波長、FSR、Q 都與真實元件不同。需要定量時請改用 3D 或以 MPB 求 n_eff。
- **波導可能不是單模**：以對稱平板波導粗估，`W`=0.5 µm、折射率 2.8 與 1.44 時 V 約 2.4，大於單模截止值（約 π/2），可能存在第二個導波模態。光源主要激發基模，但仍可能有少量能量耦合到高階模。這是粗估，尚未用 MPB 驗證。
- **Δn、Δα 為示意值**：電壓與空乏區寬度、Soref 公式的換算都沒有內建，由使用者輸入。只在空乏環帶改變，但空乏區假設對稱、寬度與電壓的關係沒有模擬（見 5.1）。
- **光源為簡化設定**：使用 Ez 點源沿波導截面鋪開，主要激發基模；若要更乾淨的基模激發，可改用 `mp.EigenModeSource`。
- **解析度**：`RESOLUTION=20` 時像素為 50 nm，`GAP` 只有 4 個像素（gap=0.2 µm），共振位置與深度會有誤差。最終結果請用較高解析度重跑並確認收斂。
- **取樣與停止條件**：`DECAY` 太鬆會在環內場尚未衰減完時就停止，頻譜出現假的起伏甚至 T>1；`NFREQ` 太少會漏掉窄的凹谷。
- 程式尚未與實驗數據或其他模擬軟體比對。

### 10.1 疑難排解：換了解析度之後，圖上的凹谷被切掉、位移接近 0、Q 變成 nan

**現象。** 單組執行（`python micro_ring_modulator_meep.py`）改了 `RESOLUTION`（或 R、gap）之後，圖上凹谷只剩一半、ON 變成一條平線、位移接近 0 或 nan。

**原因。** 不是模擬壞掉，而是共振跑出掃描窗口。解析度變高時，共振會往短波長飄（格點造成的系統差，可達數 nm），預設窗口沒有跟著移，凹谷被切掉。圖上的位移與其他數字都是從被切掉的資料算出的假數字，**不要引用**。

**為什麼自動修正可能救不回來**（根據程式碼判斷，沒有重跑驗證）：被切掉後露出的凹谷很淺，低於 `no_dip` 的門檻（0.1 dB），會先被判成「凹谷太淺」，而不是「凹谷在窗口邊緣」，窗口平移的重試沒有被觸發。這是目前檢查順序的已知弱點，**尚未修改**。

**解法。** 把窗口改成同時涵蓋 OFF 與 ON 兩個共振，並且寬度小於 FSR（否則會抓到別的共振）。先用寬窗口跑一次，從圖上量出共振位置，再把窗口中心放在那附近、寬度約 20 nm（`WVL_MIN`、`WVL_MAX`，單位 µm）。R、gap、解析度改變時共振位置都會變，必須重新量。

**預防。**
- 每次換解析度、R 或 gap，先看圖上兩個共振是否都在窗口內，而且 `shift_nm` 是否合理（預設約 +0.04 nm）。偏離很多，幾乎一定是窗口問題。
- 批次掃描（`sweep_resolution_gap.py`，不掃 R 時）會讓下一組的窗口跟著上一組的有效結果走，不會有這個問題；掃 R 時窗口取 1.1 個 FSR 寬。單組執行 `main()` 沒有這個機制。
- 在程式中呼叫 `evaluate` 時，可用 `center_um` 引數把窗口放在預測的共振位置。
- 同一批資料固定用同一個解析度，也就不需要重新換窗口。

## 11. 接上逆向設計

`evaluate(p)` 接受一組參數字典，回傳指標字典，可直接當作最佳化或機器學習的**前向模擬器**：

```python
from micro_ring_modulator_meep import PARAMS, evaluate, figure_of_merit, predict_center

cache = {}                                  # 參考光譜快取，多次呼叫共用，省掉重複的參考模擬
p = dict(PARAMS, GAP=0.12)                  # 修改要探索的參數
m = evaluate(p, ref_cache=cache)            # 回傳 ER_dB、phase_eff_rad_per_V、VpiL_Vcm、shift_nm、lam0_off_nm、valid、reason ...

if m["valid"]:                              # 只有可信的結果才拿來訓練
    score = figure_of_merit(m)              # 單一分數，越大越好

# 改變 R（變動很大，例如 3 -> 5 µm）：共振位置無法預測，
# 改成窗口取 1.1 個 FSR 寬，並只分析最深的那個凹谷（做法與 sweep_resolution_gap.py --Rs 相同）
import numpy as np
R = 5.0
fsr = 1.54 ** 2 / (2.9 * 2 * np.pi * R)     # 估算的 FSR (µm)；2.9 是 2D 模型的群折射率
p = dict(PARAMS, R=R, WVL_MIN=1.54 - 0.55 * fsr, WVL_MAX=1.54 + 0.55 * fsr,
         NFREQ=1500, ISOLATE_DIP=True, FSR_EST_UM=fsr)
m2 = evaluate(p, ref_cache=cache)

# R 只小幅變動（約 1% 內）時，才適合用 predict_center 預測共振位置：
# center = predict_center(R_new=3.03, R_ref=3.0, lam_ref_um=1.5404)
# m3 = evaluate(dict(PARAMS, R=3.03), ref_cache=cache, center_um=center)
```

`figure_of_merit` 對無效設計回傳固定的懲罰分數，而不是 nan，讓最佳化器避開那一區；原因仍保留在 `reason`。其中的加權只是示範，請依實際目標修改。`example_scan_R` 示範小幅掃描 `R` 並用 `predict_center` 追蹤共振（R 大幅變動請用上面的 `ISOLATE_DIP` 做法或 `sweep_resolution_gap.py --Rs`）。

建議的設計變數是 `R`、`GAP`、`W`，以及 PN 調變的參數（`V_REV`、`NA`、`ND`、`X_JUNC`）。哪些變數最重要，要等新模型的掃描結果出來才知道。典型做法有兩種：

- **資料集加代理模型**：批次掃描參數，建立「參數 → 光譜或指標」資料集（只收 `valid=True` 且解析度一致的資料），訓練神經網路當代理模型，再用最佳化演算法反推設計。
- **梯度法**：Meep 內建 adjoint solver，可對像素化的形狀求梯度（需另外把結構改寫成可微分的設計區域）。

Meep 每次模擬耗時是主要瓶頸，建議先用低解析度的 2D 版本做大量掃描，最後再用高解析度驗證最佳解。

## 12. 執行時間

舊模型的耗時資料已移除（耗時主要由環內的光漏完要多久決定，也就是 Q；換了損耗與摻雜之後 Q 變了，舊數字不能參考）。請在新模型上自己量：`sweep_resolution_gap.py` 會把每組的耗時寫進 CSV 的 `elapsed_s` 欄。

定性的規律（與物理和程式結構有關，不是某批資料的結果）：

- 解析度越高越慢，而且增加得很快（格點數與時間步數都增加）。
- R 越大，計算區域越大（面積約隨 R² 增加），越慢。
- Q 越高，環內的光要更久才漏完，越慢。
- 可用 `mpirun -np 4` 平行加速；實際加速倍數視機器而定。
