# 以 Meep 模擬矽光子微環調變器（2D FDTD）

本專案用開源 FDTD 軟體 [Meep](https://meep.readthedocs.io/) 模擬矽光子**微環調變器**（micro-ring modulator），輸出結構平面圖、穿透率對波長的光譜，並自動計算共振波長、Q 值、消光比等指標。程式已包成可重複呼叫的函式，目標是之後接上**逆向設計**（機器學習或最佳化演算法）。

> **狀態：** 流程已在真實 Meep 資料上跑通，並完成「解析度」與「gap」兩組掃描（見第 10 節）。目前採用 2D 等效折射率近似，結果用來驗證流程與看趨勢，**不代表真實元件的絕對數值**。主要發現：電壓造成的共振位移很穩定，但目前這組設計（R=3 µm）調變 ER 最高只有約 0.5 dB，瓶頸是環自身的損耗，而不是 gap。

## 1. 背景原理

**研究目標。** 以模擬為主，結合機器學習，對微環調變器做逆向設計：給定想要的光學表現（例如亮暗差大、損耗小），由演算法反推環半徑、間隙等結構參數，並比較不同機器學習演算法在準確度與運算時間上的差異。Meep 在這裡扮演「前向模擬器」：給一組結構參數，算出光譜與指標，作為訓練資料與驗證依據。

**Meep 的角色與限制。** Meep 只求解光（麥克斯威方程），不處理電學。因此本專案把「電壓」簡化成「折射率變化 Δn 與吸收變化 Δα」兩個輸入參數，分別跑「電壓 OFF」與「電壓 ON」兩次模擬後比較光譜。Δn、Δα 與載子濃度的關係可由 Soref 公式換算（目前程式以示意值輸入，尚未內建換算）。

微環調變器的運作原理（含共振為何會讓直波導出口出現凹谷）請見下一節 2.1。

## 2. 模擬架構

### 2.1 微環調變器怎麼運作

**元件組成。** 一條直波導（bus waveguide）、一個環形波導（ring），兩者之間隔著一條很窄的縫（gap，約 0.1 到 0.2 µm）。光從直波導左端進入、右端（through port）離開，我們量的就是右端剩下多少光。

```
            ┌──────────────┐
         ┌──┘   環 (ring)  └──┐
         │                    │
         └──┐              ┌──┘
            └──────┬───────┘
                   │ gap（耦合區）
 輸入 ═════════════╧═══════════════► 輸出（through port）
              直波導 (bus)
```

**光怎麼進到環裡（耦合）。** 光在波導內傳播時，有一小部分電場會滲到波導外面，稱為倏逝波（evanescent field）。gap 夠窄時，這部分電場會碰到環，把一部分光傳進去。用兩個係數描述：自耦合係數 `t`（直接通過的振幅比例）與交叉耦合係數 `κ`（進入環的振幅比例）。無損耦合器滿足 `t² + κ² = 1`。gap 越小，`κ` 越大，而且 `κ` 隨 gap 近似指數式變化，所以 gap 對耦合強度非常敏感。

**共振條件。** 光在環內繞一圈會累積相位：

```
φ = 2π · n_eff · L / λ        （L = 2πR 為環的周長，n_eff 為等效折射率）
```

繞一圈回來時，若相位剛好是 2π 的整數倍（`φ = 2πm`），這一圈的光與新進來的光同相，一圈一圈疊加，這就是共振：

```
λ_m = n_eff · L / m           相鄰兩個共振的間距（FSR） ≈ λ² / (n_g · L)
```

本專案 R=3 µm 時，較粗的掃描量到 FSR 約 41 到 44 nm，對應群折射率 n_g 約 3。

**為什麼共振時，直波導出口會出現凹谷（核心）。** 出口的光是兩條路徑的疊加，也就是干涉：

- **路徑 A**：光直接沿直波導通過，不進環。振幅是 `t · E_in`。
- **路徑 B**：光先耦合進環，在環裡繞了一圈（或很多圈），再耦合回直波導。耦合進去與耦合出來各帶一次 90° 的相位，合計 180°，所以路徑 B 相對路徑 A 是反相（符號相反）。

兩條路徑如何疊加，取決於繞圈相位 `φ`：

- **共振時（`φ = 2πm`）**：環內的光每一圈都同相累積，路徑 B 的強度很大，而且與路徑 A 反相，產生**相消干涉**，出口的光變少，穿透率 T 出現凹谷。
- **離開共振時**：每一圈的相位不同，不同圈的光互相抵消，路徑 B 很弱，幾乎沒有干涉，T 約等於 1。

換成能量的說法：共振時大量的光被「存」進環裡，環有損耗（材料吸收、彎曲輻射、側壁散射），這些光在環裡被消耗掉，沒有回到直波導，所以出口變暗。

> **重要：** 如果環完全沒有損耗，進環的光最後會全部回到直波導，只有相位被改變，T 永遠等於 1，不會有凹谷。凹谷是「耦合」與「損耗」的平衡所產生的。

令 `a` 為環繞一圈後振幅剩下的比例（`a = 1` 代表無損），標準的全通（all-pass）環形共振器穿透率為：

```
T(φ) = (a² − 2·a·t·cos φ + t²) / (1 − 2·a·t·cos φ + (a·t)²)

共振時（cos φ = 1）：  T_min = ( (a − t) / (1 − a·t) )²
```

**三種耦合狀態。** 凹谷多深，取決於「光進環的速度」與「光在環裡損失的速度」是否相當：

| 狀態 | 條件 | 共振時 T_min | 對應的 gap |
|---|---|---|---|
| 欠耦合（under-coupled） | 進環速度 < 損耗速度（`t > a`） | 凹谷淺 | gap 偏大 |
| 臨界耦合（critical） | 兩者相等（`t = a`） | 理論上降到 0（完全消光） | 剛好 |
| 過耦合（over-coupled） | 進環速度 > 損耗速度（`t < a`） | 凹谷又變淺 | gap 偏小 |

用 Q 值表示更直觀：令 `Q_c` 對應「光耦合進出環」的速率、`Q_i` 對應「環自身損耗」的速率（Q 越大代表速率越慢），則

```
1/Q_L = 1/Q_i + 1/Q_c                  （Q_L 是實際量到的 Q，FWHM = λ₀ / Q_L）
T_min = ( (1/Q_i − 1/Q_c) / (1/Q_i + 1/Q_c) )²
```

當 `Q_c ≫ Q_i`（進環很慢）就是欠耦合，凹谷很淺；`Q_c = Q_i` 是臨界耦合。

**怎麼拿來做調變器。** 對矽施加電壓，改變載子濃度，透過電漿色散效應（Soref 效應）改變折射率 `Δn`（以及吸收 `Δα`），等效折射率 `n_eff` 改變，繞圈相位 `φ` 隨之改變，共振波長位移：

```
Δλ ≈ λ · Δn_eff / n_g
```

雷射波長固定，放在凹谷的斜坡附近。電壓 ON/OFF 時凹谷左右移動，雷射波長處的穿透率隨之改變，亮暗即對應 1 與 0。亮暗差（OMA）取決於兩件事：位移相對於凹谷寬度（`Δλ / FWHM`），以及凹谷夠不夠深（ER）。吸收的改變 `Δα` 則會改變 `a`，進而改變凹谷的深度與寬度。

**Meep 在這裡做什麼。** Meep 不使用上面的公式，而是直接在空間與時間的格點上推進麥克斯威方程：從直波導左端送入一個寬頻脈衝，等光通過、環內的光漏完之後，對出口記錄到的場做傅立葉轉換，得到各波長的穿透率。上面的公式只用來「解讀」模擬結果、判斷設計落在哪個耦合狀態。

### 2.2 模擬流程

```
              y
              ^        ┌──────────┐
              |      ┌─┘   環     └─┐        環：圓心在 (0,0)，中心線半徑 R
              |      │    (矽)      │        直波導：位於環下方，gap 為間隙
              |      └─┐          ┌─┘
              |        └──────────┘
   光源 ─►  ═════════════════════════════►  through 監測器
              └──────────── 直波導 ───────────> x
```

1. **幾何**：矽（等效折射率 2.8）的直波導與環，背景為 SiO₂（折射率 1.44），四周為 PML 吸收邊界。
2. **光源**：直波導左端放寬頻高斯脈衝（Ez 極化）。
3. **監測**：直波導右端（環的耦合區之外）放 flux 監測器，記錄各頻率的穿透功率。
4. **三次模擬**：
   - 參考：只有直波導，用來扣掉光源頻譜與波導本身的影響。
   - 電壓 OFF：環為原本的矽。
   - 電壓 ON：環的折射率加上 `DN_ON`，並加入吸收 `DALPHA_ON`。
5. **歸一化**：穿透率 `T(λ) = 有環的功率 / 參考功率`。
6. **指標萃取**：從 `T(λ)` 抓出凹谷位置、半高寬、Q、消光比，並比較 OFF/ON 得到調變指標。
7. **有效性檢查**：檢查凹谷是否可信（見第 8 節），不合格則標記無效或自動重試。
8. **停止條件**：等環內場衰減到 `DECAY` 以下才停止（Q 越高跑越久）。

## 4. 使用方式

```bash
# 單核執行
python micro_ring_modulator_meep.py

# 平行執行（需安裝 MPI 版 Meep）
mpirun -np 4 python micro_ring_modulator_meep.py
```

執行結束後，終端機會印出各項指標，並在目前資料夾產生圖檔與光譜資料。

放大圖的範圍由程式開頭的 `PLOT_ZOOM` 控制（兩個凹谷外側各多留幾倍 FWHM，預設 1.5，數字越小畫面越放大）。長時間模擬跑完後，想調整圖的範圍，不必重跑 Meep：

```bash
python replot_from_npz.py --zoom 1.0            # 更放大
python replot_from_npz.py --xlim 1537 1542      # 手動指定 x 軸範圍 (nm)
```

**第一次使用建議先用低成本設定確認流程**：在 `PARAMS` 中把 `RESOLUTION` 設為 20 到 25、`NFREQ` 設為 200 到 600，確認結果合理後再提高解析度與降低 `DECAY`。

## 5. 參數說明

所有參數集中在程式開頭的 `PARAMS`（長度單位 µm）。參數分兩類：**設計參數**是真實元件的結構或物理量，是逆向設計要調整的旋鈕；**數值參數**只影響模擬算得準不準、跑多久，不是設計的一部分。

| 參數 | 預設值 | 類型 | 說明 |
|---|---|---|---|
| `R` | 3.0 | 設計 | 環中心線半徑 |
| `W` | 0.5 | 設計 | 波導寬度（環與直波導相同） |
| `GAP` | 0.20 | 設計 | 直波導邊緣與環邊緣的間隙，決定耦合強度 |
| `DN_ON` | −0.004 | 設計 | 電壓 ON 的折射率變化（示意值） |
| `DALPHA_ON` | 0.0 | 設計 | 電壓 ON 的額外吸收，單位 cm⁻¹（先設 0，只看折射率造成的位移） |
| `N_SI` | 2.8 | 材料 | 矽的等效折射率（2D 近似） |
| `N_CLAD` | 1.44 | 材料 | 包覆層 SiO₂ 的折射率 |
| `RESOLUTION` | 40 | 數值 | 每 µm 的像素數 |
| `NFREQ` | 1200 | 數值 | 頻率取樣點數，決定光譜的細緻度 |
| `DECAY` | 1e-6 | 數值 | 場衰減到多小才停止，越小越準但越慢 |
| `USE_HARMINV` | True | 在 OFF 的環模擬中加 Harminv，直接從時域衰減量 Q（尚未在真實 Meep 上驗證；出錯時改成 False） |
| `ISOLATE_DIP` | False | True 時窗口可比 FSR 寬，分析只取最深的那個凹谷附近（掃 R 用） |
| `FSR_EST_UM` | 0.0 | `ISOLATE_DIP=True` 時的 FSR 估計 (µm)；擷取範圍為凹谷兩側各 0.45 倍 FSR |
| `DPML` | 1.0 | 數值 | PML 厚度 |
| `WVL_MIN`, `WVL_MAX` | 1.535, 1.555 | 數值 | 掃描波長範圍（要小於 FSR，且涵蓋 OFF 與 ON 的凹谷） |

主要函式：

| 函式 | 用途 |
|---|---|
| `run_spectrum` | 跑一次模擬，回傳各頻率的穿透功率 |
| `analyze_dip` | 從光譜找凹谷，回傳 λ₀、FWHM、Q、ER |
| `modulator_metrics` | 比較 OFF/ON，回傳 OMA、調變 ER、IL |
| `check_dip` | 檢查一條光譜的凹谷是否可信（見第 8 節） |
| `adjust_for_retry` | 檢查不合格時，嘗試自動修正（平移窗口、加嚴 DECAY） |
| `fit_dip` | 對凹谷做洛倫茲擬合，回傳 λ₀、FWHM、Q、ER 與 Q 的不確定度 |
| `pick_harminv_mode` | 從 Harminv 找到的模態中，挑出最接近凹谷位置的那一個，回傳它的 Q |
| `isolate_main_dip` | 窗口內有多個共振時，只保留最深的那個凹谷附近的資料 |
| `predict_center` | 由已知結果預測新 R 的共振位置；**只適用 R 小幅變動（約 1% 內）** |
| `evaluate` | 從參數到指標的完整流程，含檢查與自動重試（逆向設計用） |
| `figure_of_merit` | 把指標變成單一分數，無效設計給固定懲罰分數 |

| `mrm_transmission.png` | 穿透率對波長（自動放大到兩個凹谷附近）；上圖為 OFF/ON 光譜，標題顯示共振位移與 Q，圖例標出雷射位置與 OMA；下圖為 ΔT = T_on − T_off |
| `mrm_transmission_full.png` | 同一份資料的完整掃描範圍總覽 |
| `mrm_spectra.npz` | 波長 `wvl_um`、`T_off`、`T_on` 陣列，可用於後續分析、重畫圖或機器學習訓練資料 |
| `sweep_spectra/*.npz` | 掃描時每一組的完整光譜（`sweep_resolution_gap.py` 自動存，檔名如 `R5.0_gap0.08_res50.npz`），之後可不重跑 Meep 而重新分析 |
| `sweep_results_v2.csv` | 掃描結果，每組一列、共 23 欄（欄位見第 9 節），每跑完一組就寫入一列 |
| `mrm_cross_compare.xlsx` | R × gap × 解析度 交叉比對表：把 CSV 貼進去，自動填好各指標的對照表與收斂檢查（用法見 9.2） |

## 7. 指標定義

| 指標 | 定義 |
|---|---|
| `λ₀` | 凹谷最低點對應的共振波長 |
| `FWHM` | 在最亮與最暗的正中間高度所量得的凹谷寬度 |
| `Q` | `λ₀ / FWHM`，越高共振越尖銳（這裡的 Q 是實際量到的 Q_L） |
| `ER` | `10·log10(T_max / T_min)`，單一凹谷的深度（dB） |
| 共振位移 | OFF 與 ON 的 `λ₀` 差 |
| `OMA` | 在雷射波長 `λ_L` 的 `\|T_on − T_off\|`，調變振幅 |
| 調變 `ER` | `10·log10(亮 / 暗)`，在 `λ_L` 處比較兩狀態 |
| `IL` | `−10·log10(亮狀態的 T)`，插入損耗 |

目前程式把 `λ_L` 取在「OFF 與 ON 差最大」的波長。

### 7.1 Q 的三種量法

凹谷只有 2 到 3% 深、漣漪約 0.3% 時，半高寬法不夠穩（同一組設計重跑，Q 曾差 34%），所以程式同時提供三種量法，並在 CSV 與試算表中並列：

| 欄位 | 方法 | 特點 |
|---|---|---|
| `Q` | 半高寬法：用最亮點、最暗點與半深度交叉點 | 簡單，但最亮點會被漣漪拉高而偏差，淺凹谷下誤差大 |
| `Q_fit`、`Q_fit_err` | 洛倫茲擬合：用凹谷附近全部的點，並給出 Q 的相對不確定度 | 雜訊互相平均。用合成資料（凹谷深 2.7%、漣漪 0.3%）測試 300 次：半高寬法 Q 偏低約 9%、散布約 15%；擬合偏差約 +2%、散布約 8%。擬合自報的不確定度（約 4%）只含隨機雜訊，約為實際散布的一半 |
| `Q_harminv` | Meep 的 Harminv：光源關掉後，由環內一個點的時域衰減量 Q | 不需要凹谷夠深，是最獨立的交叉驗證；**尚未在真實 Meep 上驗證** |

試算表的「Q 採用值」優先用 `Q_fit`（沒有時退回半高寬法），收斂判定與 R 彙整都用採用值；「Q 一致性」欄顯示 `Q_harminv / Q_fit`，偏離 1 太多代表其中一種量法有問題。ER 同理有 `ER_dB`（半高寬法）與 `ER_fit_dB`（擬合）。

### 7.2 CSV 欄位逐欄說明

`sweep_resolution_gap.py` 輸出的 CSV 共 23 欄，順序與 `mrm_cross_compare.xlsx`「貼上區」的 A~W 欄一致。數值算不出來時（例如凹谷不完整量不到半高寬）該格留空白。除非特別註明，「OFF」指無電壓、「ON」指有電壓（折射率改變 `DN_ON`）。

**A. 這一組的設定（輸入，不是量測值）**

| 欄位 | 單位 | 意義 |
|---|---|---|
| `resolution` | 像素/µm | 解析度，Meep 把每 1 µm 切成幾格；格點邊長 = 1/`resolution` µm。它不是設計參數，是數值精度（見 10.2）。 |
| `gap` | µm | 直波導邊緣到環外緣的最短距離（不是中心距）。越小耦合越強（見 10.3）。 |
| `R` | µm | 環「中心線」的半徑。環的內、外緣分別是 R ∓ W/2。 |

**B. 這組結果可不可信**

| 欄位 | 單位 | 意義 |
|---|---|---|
| `valid` | True / False | OFF 與 ON 兩條光譜都通過第 8 節的檢查才是 `True`。`False` 時其餘欄位只供除錯，不要拿去訓練。注意：它主要是看凹谷深度有沒有超過 0.1 dB 門檻，不是品質分數（見 9.3）。 |
| `reason` | 文字 | `ok`，或「OFF: 原因；ON: 原因」，原因對應第 8 節的錯誤代碼（`no_dip`、`edge_low` 等）的中文說明。 |
| `retries` | 次數（0 到 2） | 自動修正的次數：窗口平移，或把 `DECAY` 縮小 100 倍後重跑。大於 0 代表實際用的窗口或 `DECAY` 和你一開始設定的不同。 |

**C. 掃描窗口**

| 欄位 | 單位 | 意義 |
|---|---|---|
| `window_min_nm`、`window_max_nm` | nm | 最後一次實際使用的掃描窗口兩端。若有重試平移，是平移後的位置。掃 R 時窗口寬約 1.1 個 FSR。共振（含 ON 與 OFF）必須都落在這個範圍內，否則數值是假的（見 11.1）。 |

**D. 共振位置與位移**

| 欄位 | 單位 | 意義 |
|---|---|---|
| `lam0_off_nm` | nm | OFF 光譜最深點的波長，即共振波長。它隨解析度持續漂移（格點色散），**絕對值只能在同一解析度內比較**。 |
| `lam0_on_nm` | nm | ON 光譜最深點的波長。`DN_ON < 0` 時比 OFF 短。 |
| `shift_nm` | nm | `lam0_on_nm − lam0_off_nm`。負值代表往短波長移。目前所有可信資料都約 −2.15 nm，由 `Δλ ≈ λ·Δn/n_g` 決定。若任一邊的凹谷被窗口切掉，這個值會是假的（例如 −0.03 nm）。 |

**E. 凹谷的寬度與 Q（都是 OFF 的凹谷）**

| 欄位 | 單位 | 意義 |
|---|---|---|
| `fwhm_nm` | nm | 半高寬：在最亮與最暗正中間的高度所量得的凹谷寬度（半高寬法）。凹谷不完整時留空白。 |
| `Q` | 無因次 | `lam0_off_nm / fwhm_nm`，半高寬法的 Q。凹谷只有 2 到 3% 深時誤差可達三成（見 7.1）。 |
| `Q_fit` | 無因次 | 洛倫茲擬合得到的 Q，用凹谷附近全部的點，比 `Q` 穩。`mrm_cross_compare.xlsx` 的「Q 採用值」優先用它。 |
| `Q_fit_err` | 比例 | `Q_fit` 的相對 1σ 不確定度（0.01 = 1%）。只含隨機雜訊，約為實際散布的一半，漣漪造成的系統偏差不在內。 |
| `Q_harminv` | 無因次 | Meep 的 Harminv 在光源關掉後，由環內一點的時域衰減量出的 Q。**目前每一組都是空白**（沒找到接近凹谷的模式，原因未查明）。 |

**F. 凹谷深度（OFF 單一凹谷）**

| 欄位 | 單位 | 意義 |
|---|---|---|
| `ER_dB` | dB | `10·log10(T_max / T_min)`，`T_max` 取窗口內的最大值，所以漣漪會讓它偏大。 |
| `ER_fit_dB` | dB | 同樣的深度，但用擬合曲線的基線與谷底來算，較不受單點雜訊影響。「凹谷 ER 採用值」優先用它。 |

**G. 調變器指標（OFF 與 ON 比較）**

雷射波長 `lam_L_nm` 取在「|T_on − T_off| 最大」的位置，下面三個指標都在這個波長算。

| 欄位 | 單位 | 意義 |
|---|---|---|
| `lam_L_nm` | nm | 程式自動選的雷射波長，也就是兩個狀態差最大的地方。 |
| `OMA` | 無因次（0 到 1） | 光調變振幅 `\|T_on − T_off\|`，越大調變越明顯。 |
| `ER_mod_dB` | dB | 調變消光比 `10·log10(亮 / 暗)`。這才是調變器真正的 ER，目標是 3 dB 以上；它與 `ER_dB`（單一凹谷深度）不同。 |
| `IL_dB` | dB | 插入損耗 `−10·log10(亮狀態的 T)`，越小越好。 |

**H. 耗時**

| 欄位 | 單位 | 意義 |
|---|---|---|
| `elapsed_s` | 秒 | 這一組 `evaluate` 的牆鐘時間，含參考、OFF、ON 三次模擬與重試。與 MPI 程序數、電腦有關，只能在同一台機器、同樣的設定下比較。 |

## 8. 資料有效性檢查

逆向設計會用大量不同參數呼叫 `evaluate`。參數一改，共振位置就會移動（例如 `R` 變 1.7%，共振約移 26 nm），可能跑出掃描窗口、窗口內出現兩個共振，或模擬沒跑到收斂。這些情況下 `analyze_dip` 仍會算出數字，但數字是錯的。因此 `evaluate` 會對 OFF 與 ON 兩條光譜做檢查，並在回傳的字典中帶有 `valid` 與 `reason`：

| 錯誤代碼 | 意義 | 自動處理 |
|---|---|---|
| `not_converged` | T 明顯大於 1，環內的光還沒漏完就停了 | 把 `DECAY` 縮小 100 倍後重跑 |
| `no_dip` | 凹谷深度低於 0.1 dB（共振可能完全在窗口外，或耦合太弱而太淺） | 無法自動修正 |
| `edge_low` / `edge_high` | 凹谷在窗口邊緣，可能被切掉 | 朝凹谷那一側平移窗口後重跑 |
| `incomplete` | 凹谷量不到半高寬 | 同上，平移窗口 |
| `multi` | 窗口內有多個共振。判斷方式：先做 5 點移動平均、以中位數為基線，再用遲滯（低於「基線 − 0.3 倍深度」算進入凹谷，回升到「基線 − 0.1 倍深度」以上才算離開）數凹谷個數，避免雜訊在門檻附近來回穿越而把一個凹谷誤數成多個 | 無法自動修正，請縮小 `WVL_MIN`、`WVL_MAX` 或改 `R` |

模擬本身失敗（當機、記憶體不足）也會被攔下，回傳 `valid=False`，不會讓批次中斷。

**限制：** 窗口追蹤只在共振「剛好跑出邊緣、仍看得到凹谷的一側」時有效（以預設參數約為 `R` 變動 1% 內）。若共振完全離開窗口，光譜是平的，程式無法知道該往哪個方向移，會回報 `no_dip`。此時請用 `predict_center` 預測共振位置，並透過 `center_um` 引數放置窗口。

**`predict_center` 也有限制：** 它假設「同一個階數 m」，即 λ 與 R 成正比，所以只適用 R 小幅變動。R 從 3 變成 5 µm 時，同一階的共振會從約 1540 nm 跑到約 2570 nm，完全不是我們要的波段。R 大幅變動時請改用 `ISOLATE_DIP`：窗口取約 1.1 個 FSR 寬（窗口內至少有一個完整的共振，不必知道它在哪），再讓 `evaluate` 只分析最深的那一個。`sweep_resolution_gap.py --Rs` 就是這樣做的（見第 9 節）。這套檢查邏輯先用合成光譜測試，再由第 10 節的真實掃描實際使用（沒有觸發重試）。

**門檻的現況：** `no_dip` 的門檻 0.1 dB 是經驗值。第 10 節的掃描中，解析度 40 與 50 兩組的凹谷 ER（0.092、0.079 dB）略低於門檻而被標為 `valid=False`，但它們的位移與 Q 都與其他組一致，是真實但很淺的凹谷，不是模擬失敗。建議之後把門檻降到約 0.05 dB（約為雜訊的 4 倍）。第二批掃描（10.7）又顯示：R=4 時深度落在 0.06 到 0.15 dB，`valid` 會隨解析度在 True 與 False 之間翻轉，所以 `valid` 只代表「過了深度門檻」，不代表品質；R=5 的深度約 0.03 dB，連 0.05 dB 的門檻也過不了。

**`valid=False` 時，其餘數值僅供除錯，不要拿去訓練。**

## 9. 解析度、gap 與 R 掃描

`sweep_resolution_gap.py` 批次掃描「環半徑 R × 間隙 gap × 解析度」，每組結果寫入 CSV；`mrm_cross_compare.xlsx` 讀取這份 CSV（貼上即可），自動排成對照表並做收斂檢查。為什麼要掃這幾個參數、它們的定義與對設計的影響，見第 10 節；**掃出來的數值怎麼讀、怎麼用，見 9.2 與 9.3**。

```bash
# 解析度收斂測試（gap、R 固定）
python sweep_resolution_gap.py --resolutions 25 40 50 --gaps 0.20

# gap 掃描（解析度、R 固定）
python sweep_resolution_gap.py --resolutions 40 --gaps 0.10 0.12 0.15 0.20

# R 掃描：R 大時每組很慢，建議先從 4、5 開始
python sweep_resolution_gap.py --Rs 4 5 --gaps 0.12 --resolutions 25

# 完整交叉掃描：R × gap × 解析度 全部組合（下例 4×4×3 = 48 組），用 4 個 MPI 程序
mpirun -np 4 python sweep_resolution_gap.py --Rs 3 3.5 4 5 --gaps 0.08 0.10 0.12 0.15 --resolutions 25 40 50
```

**掃 R 的做法。** R 一變，共振位置會跑得很遠，無法預測（見第 8 節）。所以這個模式不放窗口在預測位置，而是：

- 窗口取 1.1 個 FSR 寬（`FSR = λ² / (n_g · 2πR)`，`n_g` 預設 2.9，可用 `--ng-est` 調整），窗口中心設在 `--target-nm`（預設 1540 nm）；
- 頻率取樣間隔約 0.02 nm（`--spacing-nm`），頻率點多只增加記憶體，不增加模擬時間；
- 分析時只取最深的那個凹谷兩側各 0.45 倍 FSR 的資料（`ISOLATE_DIP`），其餘共振丟掉。

模擬時間主要由環內的光漏完要多久決定，與窗口寬度幾乎無關，所以放寬窗口不會變慢。但 R 變大時計算區域變大（面積約隨 R² 增加），Q 通常也變高，每組都會比 R=3 慢。

**其他特性。**

- 每跑完一組就寫入 CSV；中斷後重新執行同一個指令，已有結果的組合會自動跳過。
- 每組的完整光譜另存到 `sweep_spectra/`，之後可以離線重新分析。
- 不掃 R 時，每組的掃描窗口以上一組有效結果的共振波長為中心（`--center-nm` 指定第一組的位置）。
- 無效結果也會寫入並附原因。
- 預設輸出 `sweep_results_v2.csv`。舊版（沒有 R 欄）的 CSV 格式不同，程式會拒絕寫入並提示改名備份。
- 目前 CSV **沒有記錄** `DECAY` 與 `NFREQ`（沿用 `PARAMS` 的值，掃 R 時 `NFREQ` 由窗口寬度決定），之後建議加入，才能完整重現。

**CSV 欄位（共 23 欄，順序與試算表 A~W 欄一致；逐欄的定義、單位與注意事項見 7.2）：** `resolution`、`gap`、`R`、`valid`、`reason`、`window_min_nm`、`window_max_nm`、`lam0_off_nm`、`lam0_on_nm`、`shift_nm`、`fwhm_nm`、`Q`、`Q_fit`、`Q_fit_err`、`Q_harminv`、`ER_dB`、`ER_fit_dB`、`OMA`、`ER_mod_dB`、`IL_dB`、`lam_L_nm`、`retries`、`elapsed_s`。

**舊的 `mrm_sweep_analysis.xlsx`。** 它的收斂判定要求同一組 (R, gap) 的列相鄰、且解析度遞增，掃描組合一多、分批貼上就會對不上，所以改用 `mrm_cross_compare.xlsx`（依 R、gap、解析度查值，與列的順序無關）。舊檔仍可看單組結果，但不建議再用於多組交叉比對。

### 9.1 暫停與繼續

腳本每跑完一組就寫入 CSV，所以可以隨時停、之後接著跑：

- **暫停：** 前景執行按 `Ctrl+C`；背景執行（`nohup`）用 `pkill -f sweep_resolution_gap.py`。已寫入 CSV 的組合都保留。
- **繼續：** 在同一個資料夾，用同一份 `.py`、同一個 `--out`，原封不動再打一次同一行指令。已有結果的組合會印 `[skip]` 並跳過，只跑剩下的。
- **停下當下正在跑的那一組不會被存下來**，下次從那一組開頭重跑。單組在解析度 50 可能要 10 到 25 分鐘（見第 13 節），盡量等一組剛印出 `[done]` 再停。
- **中途不要改物理設定**（`N_SI`、`DN_ON`、`DECAY` 等）。舊結果會和新結果混在同一個 CSV，卻沒有警告。要改設定請換新的 `--out` 檔名。
- 想放著跑一整晚，建議用 `nohup mpirun -np 4 python sweep_resolution_gap.py ... > sweep.log 2>&1 &`，視窗關掉程序才不會跟著被關。

### 9.2 掃描數值怎麼用（`mrm_cross_compare.xlsx`）

**步驟。**

1. 在「說明與設定」分頁把 R、gap、解析度的軸改成你實際掃的值（黃底藍字可改；目前資料有 R = 3、3.5、4、5，所以 R 軸要改成這四個）。同一頁會自動產生對應的指令。
2. 跑完（或跑到一半）後，開啟 `sweep_results_v2.csv`，**選取所有資料列、不含標題列**，貼到「貼上區」的 **A11**。每次都貼整份 CSV，不必只貼新增的列。
3. 看「交叉比對」：Q、凹谷 ER、調變 ER、OMA、位移、耗時、資料筆數各一塊，每塊有三張 R × gap 表（每個解析度一張）。空白代表該組合還沒有資料。
4. 看「收斂檢查」：每組 (R, gap) 列出三個解析度的 Q、ER、位移，以及相鄰解析度的變化量，最後一欄給結論。

**注意事項。**

- 「貼上區」的 A5 到 A10 是先前 R=3 的六筆舊資料，請不要動。它們與新 CSV 裡的 R=3、gap 0.10、0.12、0.15、解析度 40 是同一批結果，重複的組合會取平均（數值相同，不影響結果），「資料筆數」那塊會顯示 2。
- 「只統計 valid=TRUE 的資料？」（說明頁 B13）預設是「否」，凹谷太淺而被標成無效的資料也會進表。想只看通過檢查的資料就改成「是」。
- 欄位 X（Q 採用值）優先用洛倫茲擬合的 `Q_fit`，沒有才用半高寬法的 `Q`；欄位 Y（ER 採用值）優先用 `ER_fit_dB`，沒有才用 `ER_dB`。原因：淺凹谷的半高寬法誤差可達三成以上（見 10.5）。
- `Q_harminv` 到目前為止每一組都是空白，沒有放進比較表（原因未查明，見 10.7 的未解問題）。

**「收斂檢查」的判定規則。** 只看最高兩個解析度之間（第 2 個到第 3 個）的變化，三項都要小於容許值才算「已收斂」：位移變化 < 0.05 nm、Q 變化 < 10%、ER 變化 < 10%（容許值設定在說明頁，皆為經驗準則，可自行調整）。結果有四種：「已收斂」、「未收斂：位移 Q ER（列出沒過的項目）」、「資料不足」（缺其中一個解析度）、空白（整列沒資料）。共振波長 λ₀ 不參與判定，因為它隨解析度持續漂移、收斂得很慢，而位移、Q、ER 才是設計比較真正在意的量（10.2）。

### 9.3 讀掃描數值的規則

1. **先看「收斂檢查」，再信「交叉比對」。** 只有「已收斂」的 (R, gap) 才能當成這個設計的性能。「未收斂」的組合，只能看趨勢方向，不要拿絕對值做比較。
2. **只比較同一個解析度的數字。** 不同解析度的共振波長相差 1 到 5 nm（格點造成的系統差），Q 與 ER 也會變。要跨 R 或跨 gap 比較，請固定在同一張解析度的表內。
3. **`valid` 旗標只是「凹谷深度有沒有超過 0.1 dB 門檻」，不是品質分數。** 深度在門檻附近時，同一組設計會隨解析度在 True 與 False 之間跳（例如 R=4、gap 0.10：解析度 25 為 False、40 為 True、50 又是 False），這是門檻效應，不是物理。深度只有零點幾 dB 的 `valid=True` 資料，與 `valid=False` 的相比並沒有比較可信。
4. **凹谷很淺（< 0.2 dB，約 5%）時，Q 與 ER 都不可靠。** 解讀見 10.7：目前 R ≥ 3.5 的資料幾乎都落在這個區間。
5. **各指標分別看什麼：** 位移是最可靠的（各組都穩定在約 −2.15 nm），可以直接當 `DN_ON` 的設計依據；Q 看趨勢；ER、OMA 與調變 ER 在凹谷夠深（R=3、小 gap）時才有意義。
6. **用來訓練機器學習前：** 只取 `valid=True` 且收斂檢查通過的列；整批資料固定同一個解析度；輸入特徵取 R、gap（以及 `DN_ON`、`DALPHA_ON` 等設計參數），目標取 `ER_mod_dB`、`OMA`、`Q_fit`、`shift_nm`；`lam0_off_nm` 的絕對值不要當目標，因為它受解析度影響。

### 10.2 解析度（RESOLUTION）：為什麼要掃、它是什麼、對設計有什麼影響

**定義。** `RESOLUTION` 是每 µm 長度切成幾個格點。Meep 把空間切成方格，格點邊長是 `1 / RESOLUTION` µm，並用階梯狀的方格去近似圓形的環與很窄的 gap：

| RESOLUTION | 格點邊長 | gap = 0.20 µm 約幾格 | 環寬 0.5 µm 約幾格 |
|---|---|---|---|
| 25 | 40 nm | 5 | 12.5 |
| 40 | 25 nm | 8 | 20 |
| 50 | 20 nm | 10 | 25 |

**為什麼要取樣這個參數。** 它**不是設計參數**（真實元件沒有「格點」），而是決定「算得準不準」的數值參數。如果模擬結果會隨著解析度改變，代表我們量到的是格點造成的假象，而不是元件的物理。因此用同一個設計，換不同解析度各跑一次，看結果有沒有趨於穩定，這就是**收斂測試**。它同時決定成本：耗時大約隨解析度的 2.8 次方增加，所以要在準確度與運算時間之間取捨。

**對設計與研究的影響。** 解析度會改變「環的有效光程」和「gap 的耦合強度」，所以共振波長與凹谷深度的絕對值會跟著改變；但位移、gap 越小凹谷越深這類**相對趨勢**不受影響。對逆向設計而言，同一批資料必須使用同一個解析度，否則共振位置的系統差（1 到 5 nm）會被演算法誤當成設計的效果。

**結果（gap = 0.20 µm）：**

| 解析度 | 共振 λ₀ (nm) | 位移 (nm) | FWHM (nm) | Q | ER (dB) | 耗時 (分) |
|---|---|---|---|---|---|---|
| 25 | 1540.360 | −2.149 | 0.383 | 4027 | 0.121 | 6.2 |
| 40 | 1535.034 | −2.151 | 0.373 | 4118 | 0.092 | 21.6 |
| 50 | 1533.826 | −2.147 | 0.386 | 3977 | 0.079 | 43.3 |

**判讀：**

- **位移已收斂。** 三個解析度都是 −2.15 nm。由 `Δλ ≈ λ·Δn/n_g` 反推（假設 Δn_eff ≈ Δn），n_g 約 2.86，與 FSR 估出的約 2.96 同量級。「折射率變化 → 共振位移」這條鏈很穩，`DN_ON` 可當成可靠的設計旋鈕。
- **共振波長沒有收斂。** 隨解析度提高往短波長漂移了 5.3 nm，再漂 1.2 nm，漂移量在縮小，但到 50 仍未停止（相鄰差遠大於試算表預設的 0.2 nm 門檻）。絕對波長不能當真，只能比較同一解析度下的相對結果。
- **Q 與 ER 的判斷要保守。** Q 在三個解析度之間只差約 3%，看似穩定；但第一次試跑（推測同為解析度 25）的 Q 是 6104，與這次的 4027 差了 34%（FWHM 為 0.252 與 0.383 nm，ER 為 0.133 與 0.121 dB，共振位置則幾乎相同）。兩次的 `DECAY`、`NFREQ`、掃描窗口可能不同，原因未確認。這說明凹谷只有 2 到 3% 深時，用半高寬量出的 Q 誤差可能達三成，所以「Q 沒有隨解析度改變」只能說沒有看到明顯趨勢，不能說已經證明收斂。ER 則隨解析度單調下降（0.121 → 0.092 → 0.079 dB），幅度大於上面的重複量測差異（約 10%），可能是真實趨勢：格點變細，gap 畫得更準，耦合變得更弱。
- **耗時。** 6.2、21.6、43.3 分鐘，對應的耗時隨解析度的指數約 2.8，略低於理論推估的 3 次方。

**結論：** 大批資料建議用 `RESOLUTION = 40`（約 7 到 22 分鐘一組），最後挑出的好設計再用 50 以上驗證；40 與 50 之間共振位置仍差 1.2 nm，相對於 gap=0.20 時 0.37 nm 的 FWHM 並不小，因此只做資料集內的相對比較，不要與其他解析度的資料混用。

### 10.3 間隙（GAP）：為什麼要掃、它是什麼、對設計有什麼影響

**定義。** `GAP` 是直波導邊緣到環外緣的最短距離（µm），不是中心距。直波導中心到環中心的距離為 `R + W + GAP`。

**為什麼要取樣這個參數。** gap 是調整耦合強度（`κ`）的主要旋鈕，決定設計落在「欠耦合、臨界耦合、過耦合」哪一種（見 2.1）。只改 gap、其他全固定，觀察凹谷深度、寬度、Q 怎麼變，就能判斷目前設計在哪一側、應往哪個方向調。gap 也受製程限制（太窄做不出來），所以先看它有多大效果很有價值。

**對設計的影響（一般原理）。** gap 變小：`κ` 近似指數式變大，光更容易進環。欠耦合時，這使凹谷變深（ER 與 OMA 變大），同時實際量到的 Q 變低、凹谷變寬。凹谷變寬代表光在環內停留時間短，光學頻寬較大，一般有利於更快的調變，但也需要更大的位移才能分開亮暗。gap 小過頭則會進入過耦合，凹谷反而變淺。

**結果（`RESOLUTION` = 40）：**

| gap (µm) | 共振 λ₀ (nm) | FWHM (nm) | Q | OFF 凹谷 ER (dB) | OMA | 調變 ER (dB) | 位移/FWHM | 耗時 (分) |
|---|---|---|---|---|---|---|---|---|
| 0.10 | 1535.52 | 1.385 | 1109 | 0.607 | 0.114 | 0.53 | 1.55 | 6.8 |
| 0.12 | 1535.33 | 1.099 | 1397 | 0.336 | 0.068 | 0.31 | 1.96 | 8.2 |
| 0.15 | 1535.17 | 0.741 | 2073 | 0.179 | 0.039 | 0.17 | 2.90 | 11.8 |
| 0.20 | 1535.03 | 0.373 | 4118 | 0.092 | 0.021 | 0.09 | 5.77 | 21.6 |

（位移在四組都約為 −2.15 nm。「位移/FWHM」取位移的絕對值。）

**判讀：**

- **趨勢乾淨且符合物理。** gap 越小，凹谷越深、越寬、Q 越低；Q 的變化達 3.7 倍，遠大於量測誤差，所以趨勢是真的。耗時也隨 Q 增加（6.8 分到 21.6 分），因為 Q 越高，環內的光漏得越慢。
- **目前的設計落在欠耦合。** 判斷依據是「gap 變小，凹谷反而變深」：在欠耦合時增加耦合會使凹谷變深，過耦合則相反。
- **用簡單環模型粗估耦合與損耗**（由 Q 與 ER 反推，假設 `T_max = 1`，只是量級參考）：

| gap (µm) | Q（實測） | `Q_c`（光進環，粗估） | `Q_i`（環自身損耗，粗估） |
|---|---|---|---|
| 0.10 | 1109 | 約 3.3×10⁴ | 約 1.1×10³ |
| 0.12 | 1397 | 約 7.4×10⁴ | 約 1.4×10³ |
| 0.15 | 2073 | 約 2.0×10⁵ | 約 2.1×10³ |
| 0.20 | 4118 | 約 7.8×10⁵ | 約 4.1×10³ |

  即使 gap 縮到 0.10 µm，`Q_c` 仍比 `Q_i` 大約 30 倍，也就是光進環的速度遠慢於環裡損失的速度，所以凹谷很淺。另外，粗估出的 `Q_i`（環自身損耗）會隨 gap 變小而下降，理論上環自身的損耗不該與 gap 有關，這表示耦合區可能額外漏光，或這個簡單模型不完全適用，需要更多資料確認。
- **沒有任何一組達到調變 ER 3 dB 的目標**（最高 0.53 dB，OMA 最高 0.114）。

### 10.4 綜合結論與對設計的意義

1. **逆向設計的搜尋範圍必須包含 R。** 只調 gap，從這批資料看達不到目標：gap 已縮到 0.10 µm，Q 只剩約 1100，凹谷變寬（位移/FWHM 只剩 1.55），OMA 仍只有 0.11。原本推測更有力的槓桿是降低環自身損耗，也就是加大環半徑 R（彎曲損耗隨半徑變小）。**後來的 R 掃描（10.7）不支持這個推測**：R 從 3 加到 3.5 以上，凹谷反而變得很淺，原因尚未查明。R 目前仍應列入搜尋範圍，但不能預期「越大越好」。
2. **`DN_ON` 是可靠的設計旋鈕。** 位移對解析度與 gap 都很穩定，約 −2.15 nm。
3. **解析度要固定。** 同一批資料用同一個解析度，並在紀錄中保存 `RESOLUTION`、`DECAY`、`NFREQ`。
4. **gap 掃描等於一張迷你的設計空間地圖。** 之後機器學習找出的最佳 gap，可以與這張地圖互相對照，檢查演算法有沒有找對。

### 10.5 量測的可信度與限制

- 淺凹谷的 Q 與 ER 量測誤差大（Q 可能達三成）。**本節的 Q 與 ER 都是用半高寬法量的**；程式現已加入洛倫茲擬合與 Harminv（見第 7.1 節），但還沒有用它們重跑這批資料，所以本節的數字尚未用新方法確認。
- 共振波長的絕對值隨解析度漂移，尚未收斂。
- 早期一次試跑（`GAP`=0.15、`DALPHA_ON`=15，設定記錄不完整）曾看到電壓 ON 的凹谷比 OFF 更深，但在欠耦合下，加入損耗理論上應使凹谷變淺，兩者不一致。可能原因是當時 `DECAY` 較鬆，高 Q 的 OFF 凹谷被截斷而偏淺，但這只是假設，未驗證，建議在固定設定下重做 `DALPHA_ON` 測試。
- 上述所有結果都是 2D 等效折射率近似，尚未與 3D 或實驗比對。

- **R=3.5 的結果可重現**：解析度 25 與 40 的 ER 差不到 10%（0.114 / 0.105、0.126 / 0.120、0.138 / 0.134、0.150 / 0.153），Q 差約 2%。不是雜訊。但它的趨勢和 R=3 **相反**：gap 越大，凹谷反而稍深（0.105 → 0.153 dB），而 Q 同時變大 2.9 倍，深度只變 1.5 倍。這不符合單純「欠耦合」或單純「過耦合」的簡單環模型（兩者預測的深度變化幅度都比觀察到的大）。成因未確認。
- **R=4 的 ER 不可重現**：同一個 gap，三個解析度的 ER 在 0.06 到 0.15 dB 之間亂跳，也不隨 gap 單調變化（例如 gap 0.15：0.073 → 0.148 → 0.059 dB），`valid` 旗標隨之翻轉。這是門檻附近的雜訊等級，不要解讀。
- **R=5 的 ER 看起來有一個底：** 解析度 40 與 50 時，四個 gap 的 ER 都是 0.028 到 0.031 dB，與 gap 無關，但 Q 卻隨 gap 變化 2.7 倍。真正的耦合效應不該讓深度完全不隨 gap 改變，所以這個數字更像是量測的底，不是元件的物理。
- **R=5 的 Q（擬合）對解析度極敏感：** gap 0.08 時，解析度 25、40、50 的 Q 是 1742、7971、9351（差 4.6 倍），R=3 到 4 的相同比較只差 10% 到 16%。R=5 的 Q 目前不可信，也不要把 Q 隨 R 上升當成事實。
- 這些凹谷多半只有 1 到 3% 深，位移仍然穩定（上面第一點），表示共振還在、只是量不準，不是「沒有共振」。

**未解問題與建議的檢查（都還沒做）。**

1. 用 `replot_from_npz.py` 畫出 `sweep_spectra/R3.5_gap0.08_res40.npz` 與 `R5.0_gap0.08_res50.npz`，目視確認 OFF 與 ON 的凹谷是否各自存在、差約 2.15 nm。
2. **`DECAY` 測試**：用 `--decay 1e-8` 重跑 R=5、gap 0.08、解析度 25，與現有的 1e-6 比較。若 Q 與 ER 明顯改變，代表 R 大時模擬在環內的光還沒漏完就停了（高 Q 的光譜被截斷），R ≥ 4 的資料都要重看。
3. **R=3 到 3.5 之間的斷崖**：在 R = 3.1、3.2、3.3 補幾組（gap 0.08 與 0.10，解析度 25），看凹谷深度是逐漸變淺還是突然消失；另外在 R=3.5 把 gap 放大到 0.20、0.25、0.30，看凹谷深度會不會繼續變深。
4. `Q_harminv` 每一組都是空白，原因還沒查（可能是找不到接近凹谷的模式，或容許誤差太小）。
5. CSV 仍沒有記錄 `DECAY` 與 `NFREQ`，重現這批資料時請以當時使用的 `PARAMS` 為準。

## 11. 限制與注意事項

- **2D 等效折射率近似**：以固定的 `N_SI` 取代真實矽波導的三維模態，絕對的共振波長、FSR、Q 都與真實元件不同。需要定量時請改用 3D 或以 MPB 求 n_eff。
- **波導可能不是單模**：以對稱平板波導粗估，`W`=0.5 µm、折射率 2.8 與 1.44 時 V 約 2.4，大於單模截止值（約 π/2），可能存在第二個導波模態。光源主要激發基模，但仍可能有少量能量耦合到高階模。這是粗估，尚未用 MPB 驗證。
- **Δn、Δα 為示意值**：尚未接上電壓、PN 接面與 Soref 公式的換算，且整個環都套用同樣的 Δn（真實元件只有部分區域摻雜），位移量會被高估。
- **光源為簡化設定**：使用 Ez 點源沿波導截面鋪開，主要激發基模；若要更乾淨的基模激發，可改用 `mp.EigenModeSource`。
- **解析度**：`RESOLUTION=20` 時像素為 50 nm，`GAP` 只有 4 個像素（gap=0.2 µm），共振位置與深度會有誤差。最終結果請用較高解析度重跑並確認收斂。
- **取樣與停止條件**：`DECAY` 太鬆會在環內場尚未衰減完時就停止，頻譜出現假的起伏甚至 T>1；`NFREQ` 太少會漏掉窄的凹谷。
- 程式尚未與實驗數據或其他模擬軟體比對。

### 11.1 疑難排解：換了解析度之後，圖上的凹谷被切掉、位移接近 0、Q 變成 nan

**現象。** 單組執行（`python micro_ring_modulator_meep.py`）第一次的圖正常（共振位移 −2.15 nm、Q 約 6104），第二次把 `RESOLUTION` 調高後，圖上 OFF 的凹谷只剩右半邊，ON 是一條平線，標題變成「共振位移 = −0.03 nm、Q = nan」，圖例的雷射波長剛好落在窗口的左邊緣。

**原因。** 不是模擬壞掉，而是共振跑出掃描窗口。解析度變高時，共振會往短波長飄（格點造成的系統差，見 10.2）：R=3、gap 0.20 時，OFF 共振從解析度 25 的 1540.4 nm 移到解析度 40 的 1535.0 nm，約移 5 nm。預設窗口是 1535 到 1555 nm，OFF 的共振剛好落在下緣，凹谷被切掉；ON 的共振（約 1532.9 nm）整個在窗口外。圖上的位移與 Q 都是從被切掉的資料算出的假數字，**不要引用**。

**為什麼自動修正沒有救回來**（以下根據程式碼與圖形判斷，沒有重跑驗證）：被切掉後露出的凹谷只有約 0.09 dB，低於 `no_dip` 的門檻（0.1 dB），所以先被判成「凹谷太淺」，而不是「凹谷在窗口邊緣」，窗口平移的重試沒有被觸發。ON 整個在窗口外，也是 `no_dip`。這是目前檢查順序的已知弱點，**尚未修改**。

**解法。** 把窗口改成同時涵蓋 OFF 與 ON 兩個共振，並且寬度小於 FSR（約 41 到 44 nm，否則會抓到別的共振）。窗口中心取 OFF 與 ON 的中間位置，寬約 20 nm。下表是 R=3、gap 0.20 的參考值（OFF 共振來自實測，ON 以位移 −2.15 nm 估算）：

| 解析度 | OFF 共振 (nm) | ON 共振 (nm) | 建議 `WVL_MIN`、`WVL_MAX` (µm) |
|---|---|---|---|
| 25 | 1540.36 | 約 1538.2 | 1.530、1.550 |
| 40 | 1535.03 | 約 1532.9 | 1.525、1.545 |
| 50 | 1533.83 | 約 1531.7 | 1.522、1.542 |

R 或 gap 改變時共振位置也會變，上表不能直接套用，要重新量。

**預防。**
- 每次換解析度、R 或 gap，先看圖上兩個共振是否都在窗口內，而且 `shift_nm` 是否約 −2.15 nm。偏離很多，幾乎一定是窗口問題。
- 批次掃描（`sweep_resolution_gap.py`，不掃 R 時）會讓下一組的窗口跟著上一組的有效結果走，不會有這個問題；掃 R 時窗口取 1.1 個 FSR 寬。單組執行 `main()` 沒有這個機制。
- 在程式中呼叫 `evaluate` 時，可用 `center_um` 引數把窗口放在預測的共振位置。
- 同一批資料固定用同一個解析度，也就不需要重新換窗口。

## 12. 接上逆向設計

`evaluate(p)` 接受一組參數字典，回傳指標字典，可直接當作最佳化或機器學習的**前向模擬器**：

```python
from micro_ring_modulator_meep import PARAMS, evaluate, figure_of_merit, predict_center

cache = {}                                  # 參考光譜快取，多次呼叫共用，省掉重複的參考模擬
p = dict(PARAMS, GAP=0.12)                  # 修改要探索的參數
m = evaluate(p, ref_cache=cache)            # 回傳 Q、ER_dB、OMA、IL_dB、shift_nm、valid、reason ...

if m["valid"]:                              # 只有可信的結果才拿來訓練
    score = figure_of_merit(m)              # 單一分數，越大越好

# 改變 R（變動很大，例如 3 -> 5 µm）：共振位置無法預測，
# 改成窗口取 1.1 個 FSR 寬，並只分析最深的那個凹谷（做法與 sweep_resolution_gap.py --Rs 相同）
import numpy as np
R = 5.0
fsr = 1.54 ** 2 / (2.9 * 2 * np.pi * R)     # 估算的 FSR (µm)；2.9 是 2D 模型的群折射率
p = dict(PARAMS, R=R, WVL_MIN=1.54 - 0.55 * fsr, WVL_MAX=1.54 + 0.55 * fsr,
         NFREQ=1500, ISOLATE_DIP=True, FSR_EST_UM=fsr)
m2 = evaluate(p, ref_cache=cache)

# R 只小幅變動（約 1% 內）時，才適合用 predict_center 預測共振位置：
# center = predict_center(R_new=3.03, R_ref=3.0, lam_ref_um=1.5404)
# m3 = evaluate(dict(PARAMS, R=3.03), ref_cache=cache, center_um=center)
```

`figure_of_merit` 對無效設計回傳固定的懲罰分數，而不是 nan，讓最佳化器避開那一區；原因仍保留在 `reason`。其中的加權只是示範，請依實際目標修改。`example_scan_R` 示範小幅掃描 `R` 並用 `predict_center` 追蹤共振（R 大幅變動請用上面的 `ISOLATE_DIP` 做法或 `sweep_resolution_gap.py --Rs`）。

依第 10 節的結果，建議的設計變數是 `R`、`GAP`、`W`、`DN_ON`（其中 `R` 與 `GAP` 最重要）。典型做法有兩種：

- **資料集加代理模型**：批次掃描參數，建立「參數 → 光譜或指標」資料集（只收 `valid=True` 且解析度一致的資料），訓練神經網路當代理模型，再用最佳化演算法反推設計。
- **梯度法**：Meep 內建 adjoint solver，可對像素化的形狀求梯度（需另外把結構改寫成可微分的設計區域）。

Meep 每次模擬耗時是主要瓶頸，建議先用低解析度的 2D 版本做大量掃描，最後再用高解析度驗證最佳解。
