# 以 Meep 模擬矽光子微環調變器（2D FDTD）

本專案用開源 FDTD 軟體 [Meep](https://meep.readthedocs.io/) 模擬一個矽光子**微環調變器**（micro-ring modulator），輸出結構平面圖、穿透率對波長的光譜，並自動計算共振波長、Q 值、消光比等指標。程式已包成可重複呼叫的函式，方便後續接上**逆向設計**（機器學習或最佳化演算法）。

> 狀態：初步版本。已完成試跑並得到合理的光譜（見「模擬結果」），但採用 2D 等效折射率近似，結果用來驗證流程與趨勢，**不代表真實元件的絕對數值**。

## 背景原理

**微環共振。** 光在直波導旁的環形波導中繞行。當環的光程（折射率 × 周長）剛好是波長的整數倍時發生共振，光被耦合進環，直波導出口的穿透率在該波長出現「凹谷」。共振條件可寫成 `m·λ = n_eff · 2πR`。相鄰兩個共振的間距稱為 FSR（自由頻譜範圍）。

**調變原理。** 對矽施加電壓會改變載子濃度，透過電漿色散效應（Soref 效應）改變折射率與吸收，使共振波長位移。雷射波長固定時，凹谷移動會造成穿透光強度變化，亮暗即對應 0 與 1。

**Meep 的角色。** Meep 只求解光（麥克斯威方程），不處理電學。因此本專案把「電壓」簡化成「折射率變化 Δn 與吸收變化 Δα」兩個輸入參數，分別跑「電壓 OFF」與「電壓 ON」兩次模擬後比較光譜。Δn、Δα 與載子濃度的關係可由 Soref 公式換算（目前程式以示意值輸入，尚未內建換算）。

## 模擬架構

```
              y
              ^        ┌──────────┐
              |      ┌─┘   環     └─┐        環：圓心在 (0,0)，中心線半徑 R
              |      │    (矽)      │        直波導：位於環下方，gap 為間隙
              |      └─┐          ┌─┘
              |        └──────────┘
   光源 ─►  ═════════════════════════════►  through 監測器
              └──────────── 直波導 ───────────> x
```

程式流程：

1. **幾何**：矽（等效折射率 2.8）的直波導與環，背景為 SiO₂（折射率 1.44），四周為 PML 吸收邊界。
2. **光源**：直波導左端放寬頻高斯脈衝（Ez 極化）。
3. **監測**：直波導右端（環的耦合區之外）放 flux 監測器，記錄各頻率的穿透功率。
4. **三次模擬**：
   - 參考：只有直波導，用來扣掉光源頻譜與波導本身的影響。
   - 電壓 OFF：環為原本的矽。
   - 電壓 ON：環的折射率加上 `DN_ON`，並加入吸收 `DALPHA_ON`。
5. **歸一化**：穿透率 `T(λ) = 有環的功率 / 參考功率`。
6. **指標萃取**：從 `T(λ)` 抓出凹谷位置、半高寬、Q、消光比，並比較 OFF/ON 得到調變指標。
7. **停止條件**：等環內場衰減到 `DECAY` 以下才停止（Q 越高跑越久）。

## 環境與安裝

- Python 3
- Meep 的 Python 介面（`pymeep`）、NumPy、Matplotlib
- （選用）MPI，用於平行加速

建議以 conda 安裝（Meep 官方建議 Linux 或 macOS；Windows 請用 WSL）：

```bash
conda create -n meep -c conda-forge pymeep numpy matplotlib
conda activate meep
```

## 使用方式

```bash
# 單核執行
python micro_ring_modulator_meep.py

# 平行執行（需安裝 MPI 版 Meep）
mpirun -np 4 python micro_ring_modulator_meep.py
```

執行結束後，終端機會印出各項指標，並在目前資料夾產生圖檔與光譜資料。

放大圖的範圍由程式開頭的 `PLOT_ZOOM` 控制（兩個凹谷外各多留幾倍 FWHM，預設 4，數字越小畫面越放大）。

**第一次使用建議先用低成本設定確認流程**：在 `PARAMS` 中把 `RESOLUTION` 設為 20、`NFREQ` 設為 200，掃描範圍縮小到單一共振附近（例如 1.540 到 1.550 µm）。確認結果合理後再提高解析度與降低 `DECAY`。

## 參數說明

所有參數集中在程式開頭的 `PARAMS`（長度單位 µm）。

| 參數 | 預設值 | 說明 |
|---|---|---|
| `R` | 3.0 | 環中心線半徑 |
| `W` | 0.5 | 波導寬度（環與直波導相同） |
| `GAP` | 0.20 | 直波導與環邊緣的間隙，決定耦合強度 |
| `N_SI` | 2.8 | 矽的等效折射率（2D 近似） |
| `N_CLAD` | 1.44 | 包覆層 SiO₂ 的折射率 |
| `WVL_MIN`, `WVL_MAX` | 1.535, 1.555 | 掃描波長範圍（要小於 FSR，且涵蓋 OFF 與 ON 的凹谷） |
| `NFREQ` | 1200 | 頻率取樣點數，決定光譜的細緻度 |
| `RESOLUTION` | 40 | 每 µm 的像素數 |
| `DPML` | 1.0 | PML 厚度 |
| `DN_ON` | −0.004 | 電壓 ON 的折射率變化（示意值） |
| `DALPHA_ON` | 0.0 | 電壓 ON 的額外吸收，單位 cm⁻¹（先設 0，只看折射率造成的位移） |
| `DECAY` | 1e-6 | 場衰減到多小才停止，越小越準但越慢 |

主要函式：

| 函式 | 用途 |
|---|---|
| `run_spectrum` | 跑一次模擬，回傳各頻率的穿透功率 |
| `analyze_dip` | 從光譜找凹谷，回傳 λ₀、FWHM、Q、ER |
| `modulator_metrics` | 比較 OFF/ON，回傳 OMA、調變 ER、IL |
| `check_dip` | 檢查一條光譜的凹谷是否可信（見「資料有效性檢查」） |
| `adjust_for_retry` | 檢查不合格時，嘗試自動修正（平移窗口、加嚴 DECAY） |
| `predict_center` | 由已知結果預測新 R 的共振位置，用來放置掃描窗口 |
| `evaluate` | 從參數到指標的完整流程，含檢查與自動重試（逆向設計用） |
| `figure_of_merit` | 把指標變成單一分數，無效設計給固定懲罰分數 |

## 指標定義

| 指標 | 定義 |
|---|---|
| `λ₀` | 凹谷最低點對應的共振波長 |
| `FWHM` | 在最亮與最暗的正中間高度所量得的凹谷寬度 |
| `Q` | `λ₀ / FWHM`，越高共振越尖銳 |
| `ER` | `10·log10(T_max / T_min)`，單一凹谷的深度（dB） |
| 共振位移 | OFF 與 ON 的 `λ₀` 差 |
| `OMA` | 在雷射波長 `λ_L` 的 `\|T_on − T_off\|`，調變振幅 |
| 調變 `ER` | `10·log10(亮 / 暗)`，在 `λ_L` 處比較兩狀態 |
| `IL` | `−10·log10(亮狀態的 T)`，插入損耗 |

目前程式把 `λ_L` 取在「OFF 與 ON 差最大」的波長。

## 模擬結果

以下為一次試跑的結果，掃描 1540 到 1550 nm，使用的參數為 `R=3.0`、`W=0.5`、`GAP=0.15`、`DN_ON=−0.004`、`DALPHA_ON=15`（**與目前程式的預設值不同**，目前預設為 `GAP=0.20`、`DALPHA_ON=0`，詳見參數說明）。
測試時使用的解析度與停止條件：`RESOLUTION=（請填寫）`、`DECAY=（請填寫）`、`NFREQ=（請填寫）`。

![穿透率對波長，1540 到 1550 nm](figures/transmission_1540_1550.png)

下表數值為**從圖上目測**，非程式輸出的精確值：

| | 電壓 OFF | 電壓 ON |
|---|---|---|
| 共振波長 λ₀ | 約 1545.5 nm | 約 1543.3 nm |
| 最低穿透率 T_min | 約 0.92 | 約 0.64 |
| FWHM | 約 0.9 nm | 約 1.2 nm |
| Q | 約 1700 | 約 1300 |
| 凹谷 ER | 約 0.4 dB | 約 2 dB |

在雷射波長約 1543.3 nm 處：OMA 約 0.36，調變 ER 約 2 dB，插入損耗接近 0 dB（OFF 亮、ON 暗）。

**觀察**

- 離開共振處 T≈1，抖動約 ±0.002，代表歸一化正確。
- 電壓 ON 後共振往短波長移動約 2.2 nm。`DN_ON` 為負，折射率變小，方向正確，量級也與 `Δλ ≈ λ·Δn / n_g` 的估算相符。
- 另一次掃描 1500 到 1600 nm（較粗的取樣）看到相鄰共振間距（FSR）約 41 到 44 nm，對應群折射率約 3，量級合理。
- ON 的凹谷比 OFF 更深更寬，推測與加入的吸收 `DALPHA_ON` 有關（吸收使 Q 下降，同時可能使耦合更接近臨界耦合）。此為推測，尚未用額外模擬驗證。
- OFF 的凹谷很淺（約 0.92），因此調變 ER 偏低。可能是過耦合（光耦進環的比例遠大於環自身損耗）所致，改善方向之一是加大 `GAP`，這同樣需要用模擬確認。

## 限制與注意事項

- **2D 等效折射率近似**：以固定的 `N_SI` 取代真實矽波導的三維模態，絕對的共振波長、FSR、Q 都與真實元件不同。需要定量時請改用 3D 或以 MPB 求 n_eff。
- **Δn、Δα 為示意值**：尚未接上電壓、PN 接面與 Soref 公式的換算，且整個環都套用同樣的 Δn（真實元件只有部分區域摻雜），位移量會被高估。
- **光源為簡化設定**：使用 Ez 點源沿波導截面鋪開，主要激發基模；若要更乾淨的基模激發，可改用 `mp.EigenModeSource`。
- **解析度**：`RESOLUTION=20` 時像素為 50 nm，`GAP` 只有 3 個像素，共振位置與深度會有誤差。最終結果請用較高解析度重跑並確認收斂。
- **取樣與停止條件**：`DECAY` 太鬆會在環內場尚未衰減完時就停止，頻譜出現假的起伏甚至 T>1；`NFREQ` 太少會漏掉窄的凹谷。
- 程式尚未與實驗數據或其他模擬軟體比對。

## 資料有效性檢查

逆向設計會用大量不同參數呼叫 `evaluate`。參數一改，共振位置就會移動（例如 `R` 變 1.7%，共振約移 26 nm），可能跑出掃描窗口、窗口內出現兩個共振，或模擬沒跑到收斂。這些情況下 `analyze_dip` 仍會算出數字，但數字是錯的。因此 `evaluate` 會對 OFF 與 ON 兩條光譜做檢查，並在回傳的字典中帶有 `valid` 與 `reason`：

| 錯誤代碼 | 意義 | 自動處理 |
|---|---|---|
| `not_converged` | T 明顯大於 1，環內的光還沒漏完就停了 | 把 `DECAY` 縮小 100 倍後重跑 |
| `no_dip` | 沒有明顯凹谷（共振可能完全在窗口外，或耦合太弱） | 無法自動修正 |
| `edge_low` / `edge_high` | 凹谷在窗口邊緣，可能被切掉 | 朝凹谷那一側平移窗口後重跑 |
| `incomplete` | 凹谷量不到半高寬 | 同上，平移窗口 |
| `multi` | 窗口內有多個共振 | 無法自動修正，請縮小 `WVL_MIN`、`WVL_MAX` 或改 `R` |

模擬本身失敗（當機、記憶體不足）也會被攔下，回傳 `valid=False`，不會讓批次中斷。

**限制：** 窗口追蹤只在共振「剛好跑出邊緣、仍看得到凹谷的一側」時有效（以預設參數約為 `R` 變動 1% 內）。若共振完全離開窗口，光譜是平的，程式無法知道該往哪個方向移，會回報 `no_dip`。此時請用 `predict_center` 預測共振位置，並透過 `center_um` 引數放置窗口。以上檢查邏輯用合成光譜測試過，尚未在真實 Meep 模擬上驗證。

**`valid=False` 時，其餘數值僅供除錯，不要拿去訓練。**

## 接上逆向設計

`evaluate(p)` 接受一組參數字典，回傳指標字典，可直接當作最佳化或機器學習的**前向模擬器**：

```python
from micro_ring_modulator_meep import (PARAMS, evaluate, figure_of_merit,
                                       predict_center)

cache = {}                                  # 參考光譜快取，多次呼叫共用，省掉重複的參考模擬
p = dict(PARAMS, GAP=0.25)                  # 修改要探索的參數
m = evaluate(p, ref_cache=cache)            # 回傳 Q、ER_dB、OMA、IL_dB、shift_nm、valid、reason ...

if m["valid"]:                              # 只有可信的結果才拿來訓練
    score = figure_of_merit(m)              # 單一分數，越大越好

# 改了 R 之後，先預測共振位置再放窗口（lam_ref 是已知結果的 OFF 共振波長，單位 µm）
center = predict_center(R_new=3.05, R_ref=3.0, lam_ref_um=1.5455)
m2 = evaluate(dict(PARAMS, R=3.05), ref_cache=cache, center_um=center)
```

`figure_of_merit` 對無效設計回傳固定的懲罰分數，而不是 nan，讓最佳化器避開那一區；原因仍保留在 `reason`。其中的加權只是示範，請依實際目標修改。`example_scan_R` 是一個掃描 `R` 並自動追蹤共振的完整範例。

可探索的設計參數包括 `R`、`GAP`、`W`、`DN_ON`。典型做法有兩種：

- **資料集加代理模型**：批次掃描參數，建立「參數 → 光譜或指標」資料集（只收 `valid=True` 的資料），訓練神經網路當代理模型，再用最佳化演算法反推設計。
- **梯度法**：Meep 內建 adjoint solver，可對像素化的形狀求梯度（需另外把結構改寫成可微分的設計區域）。

Meep 每次模擬耗時是主要瓶頸，建議先用低解析度的 2D 版本做大量掃描，最後再用高解析度驗證最佳解。

## 預估執行時間

以下為依參數推算的**粗略數量級**，實際請以自己的電腦為準。時間主要由 Q 決定（光在環內漏完的時間）。

| 設定 | Q≈1000 | Q≈5000 |
|---|---|---|
| 預設（`RESOLUTION=40`、`DECAY=1e-5`）單核，每次環模擬 | 約 30 到 60 分鐘 | 約 3 到 5 小時 |
| 試跑（`RESOLUTION=20`、`DECAY=1e-3`、`NFREQ=200`）單核 | 約 2 到 5 分鐘 | 約 10 到 25 分鐘 |

一次 `evaluate` 需要跑 3 次模擬（其中參考模擬很快）。使用 `mpirun -np 4` 大約可加速 2 到 3 倍。
